# 問い合わせ一次対応マニュアル

受講生・コーチから「動かない」「表示されない」といった問い合わせが来たときに、
ビジネスサイドで一次回答するためのマニュアルです。

| 分野 | ファイル |
|---|---|
| ログイン・パスワード・メールアドレス | [login.md](login.md) |
| コーチング(予約・Meet・リマインド・記録) | [coaching.md](coaching.md) |
| AIコーチ(チャット・AIアプリ) | [ai-coach.md](ai-coach.md) |

> このファイルはコードと一緒に管理しています。画面や動きを変えたときは、同じ変更でここも直してください。
> リポジトリは公開されているため、社内のURL・アカウント名・作業手順の細部は書かないでください。

## 一次対応の流れ

1. **症状を聞き取る**: どの画面で、何をしたら、何が表示されたか。表示された文言はそのまま教えてもらう(言い換えると原因が分からなくなります)
2. **このマニュアルで該当する症状を探す**: 各項目に「考えられる原因」「確認すること」「回答例」があります
3. **答えられれば回答する**: 多くは「待てば直る」「本人の操作で直る」「管理者の操作で直る」のどれかです
4. **答えられなければエンジニアへ上げる**: 下の「エンジニアへ上げるとき」の情報を揃えて連絡します

## エンジニアへ上げるとき

次の情報があると調査が早くなります。分かる範囲で揃えてください。

- 受講生(またはコーチ)の**登録メールアドレス**
- **起きた日時**(「昨日の夜9時ごろ」程度でよい)
- **画面の名前またはURL**(例: マイページ、コーチング、AIコーチ)
- **表示された文言そのまま**、できればスクリーンショット
- 使っている端末とブラウザ(例: Windows の Chrome、iPhone の Safari)
- 何度やっても起きるか、一度だけか。ほかの人にも起きているか

次の場合は一次回答を待たず、すぐエンジニアへ連絡してください。

- 複数の人から同じ時間帯に「開けない」「ログインできない」と来ている(システム全体の障害の可能性)
- 他人の情報が見えた、身に覚えのない変更があった、など情報漏えいの疑いがある
- 受講生のデータ(学習記録・コーチング記録)が消えた

## 回答するときの注意

- パスワード・認証コード・仮パスワードを**聞かない・伝えない**。WEBCOACHからこれらを尋ねることはない、と案内メールにも書いています
- 「システムの不具合です」と断定しない。原因が分からないときは「確認してご連絡します」と答えてエンジニアへ上げる
- AIコーチの回答内容(正しい・間違い)についての問い合わせは、システムの不具合ではなくAIの性質であることが多い([ai-coach.md](ai-coach.md) 参照)
