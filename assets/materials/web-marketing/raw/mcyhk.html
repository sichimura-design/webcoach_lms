1. TikTok広告アカウントを作成する

目安の学習時間:10分

【公式】TikTok for Business: TikTok広告

TikTok for Businessは広告主様のマーケターや広告代理店の皆様がTikTokのことをより深く知ることができる公式サイトです。ここではTikTokの最新トレンドや成功事例、調査データなどをお届けします。
右上の「広告アカウント無料登録」をクリックしてください。

「今すぐ開始」をクリックしてください。

広告アカウントを作成してください。

「広告アカウントを作成する」を選択し、

会社の所在地、ビジネス名、業種、登録タイムゾーン、アカウントの通貨、電話番号を入力してください。

次の画面で会社URL、住所、支払いタイプを設定してください。

入力したら「次へ」をクリックしましょう。

2. キャンペーンの設定をする

目安の学習時間:10分

広告の目的を設定してください。

ブランド認知 → 購買意向 → コンバージョンというプロセスに沿って目的が設定されています。

  • リーチ： より多くのユーザーに広告を見てもらいたい場合
  • トラフィック： ウェブサイトやアプリの特定のページに、より多くのユーザーを誘導
  • アプリインストール： アプリインストール数を増やしたい場合
  • 動画視聴数： 動画視聴数を増やしたい場合
  • リード生成： ビジネスやブランドに対する見込み顧客を獲得
  • コミュニティインタラクション： ページのフォロー数とプロフィール訪問数を増やす
  • コンバージョン数： ウェブサイトやアプリ上で、エンゲージメントの高いアクションを促進

コンバージョン数を選択するのが一般的です。

次に「設定」を行います。

  • キャンペーン名
  • キャンペーン予算最適化
  • 予算
  • 入札方法

を選択します。

3. 広告セットの設定をする

目安の学習時間:15分

広告セットの設定に移ります。

プロモーションの目的を「アプリ」か「ウェブサイト」で選択します。

「プロモーションの目的」で「ウェブサイト」を選択し、「ウェブサイトピクセル」の項目でTikTokピクセルを作成しましょう。

まだピクセルを作成していない場合は、一番右の「+」マークから作成できます。

その上で最適化イベントを選択しましょう。

a. ピクセルを作成する

「ピクセルを作成」を選択してください。

「ウェブイベントを設定」からTikTok Pixelを選択しましょう。

なお、イベントAPIを使用する方法もあります。

「手動」を選択しましょう。

パートナー連携を使用する場合は、別途パートナーごとの解説ページを参照すると手順がわかります。

標準モードは直感的に操作がしやすいので、こちらをおすすめします。

ここでイベントを作成できます。

イベントの種類は以下の2種類です：

・特定のURLに遷移した場合に特定のイベントを発生させる

・クリックが起きたときにイベントを発生させる

ここではURLイベントを設定してみましょう。

今回はお問い合わせを送信したら「お問い合わせ」というイベントを発生させます。

お問い合わせ送信後に「thanks」ページに遷移させるのはよくある設定です。

URLが「thanks」を含む時に「お問い合わせ」というイベント名を設定します。

広告セットの設定に戻ります。

プレースメントは「自動プレースメント」を選択しましょう。

クリエイティブタイプで「ダイナミック広告」を設定すると、

複数のクリエイティブを組み合わせて自動で広告配信が行われます。

今回は設定しなくて良いでしょう。

「カスタム配信対象」を選択するとターゲットを手動で設定できます。

  • 「デモグラフィック」 は以下の通りで設定できます。
    • ロケーション
    • 言語
    • 性別
    • 年齢
  • 「ユーザーリスト」
    • ユーザーデータをターゲティングに活用することができます。
  • 「興味&行動ターゲティング」
    • 「興味関心を追加」： ユーザーの興味関心を選択できます。豊富な種類があります。
    • 「行動カテゴリーを追加：動画インタラクション」： 特定の種類の動画に対してインタラクションを行ったユーザーに配信できます
    • 「行動カテゴリーを追加：クリエイターインタラクション」： 特定の種類のクリエイターをフォローした / プロフィールを閲覧したユーザーに対して配信できます
    • 「行動カテゴリーを追加：ハッシュタグインタラクション」： 特定のハッシュタグがついた動画を視聴したユーザーに配信できます
  • 「デバイス」： OS / システムバージョン / デバイスモデル / 通信環境 / キャリア / デバイス価格を選択できます。

次に予算とスケジュールの設定です

予算額と掲載スケジュールを設定できます。

最適化の目標と入札タイプを確認したら、「次のステップ」ボタンをクリックしてください。

4. 広告の作成を行う

目安の学習時間:10分

IDについて

「TikTokアカウントを使用してSpark Adsを配信」はオンにすると、所有しているTikTokアカウントで通常投稿した動画をそのまま広告として活用できます。

プロモーションの広告フォーマットについて

  • 動画
  • 1枚の画像
  • カルーセル
  • Collection ads（コレクション広告）

から選択できます。

TikTokにおいては基本的に「動画」が効果的です。動画を選択するのがおすすめです。

動画をアップロードし、テキストを入力しましょう。

ウェブサイトURLを設定すればほとんど完了です。

トラッキングの設定が正しく行われているか確認したら、右下の「確認」ボタンをクリックして

広告を公開しましょう。
