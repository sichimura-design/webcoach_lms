修了時に完成している制作物

このコースを進めると、模写3点とオリジナル制作4〜5点、あわせて7〜8点の制作物が完成します。
それぞれどんなものか、もう少し具体的にイメージしておきましょう。
まだ聞き慣れない言葉もあるかもしれませんが、ここでは「なんとなくこんなものを作るんだな」という感覚がつかめれば十分です。
実際に作るタイミングで、あらためて詳しく説明します。

制作物 フェーズ 学べること
①Zoom背景 模写 写真を土台にテキスト・図形を重ねる基本操作
②名刺 模写 表裏2面での情報の階層整理・定型レイアウトの再現
③SNS投稿 模写 写真とテキストの重なり順を意識したレイアウト
④SNS広告バナー 実践制作 依頼書を読み解き、Canva AIでたたき台を作って仕上げる一連の流れ
⑤チラシ・Instagram投稿 実践制作 身につけた型を使って、複数媒体を効率よく作る
⑥総合演習（2媒体） 実践制作 手順書なしで、新しい依頼内容に自力で対応する
✓ Point !
実案件に近い設計

実践制作フェーズでは架空企業の依頼書（テーマカラー・必須テキスト・サイズ規定など）が用意されており、実際の発注スタイルに沿って制作を進めます。
「依頼を読み解く → たたき台を作る → 仕上げる」という本番と同じ流れで力がつきます。

学習ペースの目安

このコースは、ご自身の生活リズムに合わせて無理なく進められるように設計されています。
まとまった時間が取れない日があっても問題ありません。
大切なのは、途中で演習を省略しないことです。

! 注意
演習スキップは避けてください

テキストを読むだけ・動画を見るだけでは実力がつきません。
手を動かす演習は必ず完了させてから、次のレッスンに進んでください。

調べる心得 — まず自分で調べる

プロのデザイナーとして活動していくうえで欠かせないのが自分で調べる力です。
わからないことが出てきたとき、すぐに人に聞くのではなく、まず自分で解決を試みる癖をつけましょう。
試行錯誤を繰り返すほど、調べ方そのものが上達していきます。

今の時代の調べ方は、WEBCOACH先生やChatGPTといったAIに聞くのが最短ルートです。
Canvaの操作方法・エラーメッセージの意味など、まずはAIに疑問をそのまま貼り付けて聞いてみてください。

用途 プロンプト例
ツールエラーの解決 「Canvaで〇〇しようとしたら、画面に『△△』というエラーが表示されました。原因と対処法を教えてください。」
操作方法の確認 「Canvaで名刺サイズ（91×55mm）のテンプレートを新規作成するには、どこから操作すればいいですか？」
✓ Point !
「AIに聞く → コーチに相談」が基本の順番

疑問が出たときは、いきなりコーチに聞くのではなく、まずWEBCOACH先生やChatGPTで自力解決を試みてください。
5分ほどやってみて解決しない場合は、コーチへ遠慮なく質問しましょう。
相談するときは、①実現したいこと ②自分が行った手順 ③エラー内容 ④試したことの4要素を添えると、回答の精度が大きく上がります。

SUMMARY
  1. 修了時には模写3点＋オリジナル制作4〜5点＝計7〜8点の制作物が完成している
  2. 実践制作フェーズは架空企業の依頼書をもとに進める、実案件に近い設計
  3. ペースは自分の生活リズムに合わせてよいが、演習の省略だけは避ける
  4. 疑問が出たらまずAIに聞く → それでも解決しなければコーチへ、が基本の順番
