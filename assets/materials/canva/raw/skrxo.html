完成イメージを確認する

ここからは「習うより慣れろ」のフェーズです。
Canvaは説明を読み込んでから始めるツールではなく、実際に触りながら試行錯誤するほど早く上達するツールです。
最初から完璧に再現しようとせず、「ここはどうなってるんだろう」と気になったら、まず自分でクリックして試してみましょう。
多少お手本とズレても構いません。
手を動かした分だけ操作が体に染み込みます。

模写フェーズ最初の課題はZoom背景です。
要素数が少なく、写真1枚とテキスト・図形の組み合わせだけで作れるため、模写フェーズの中では一番取り組みやすい課題です。
上のお手本とできるだけ同じになるように模写してみましょう。

🎬 イメージしてみよう
写真1枚から始める

Canva内の無料ストック写真を1枚選ぶところから始めます。
「ゼロから絵を描く」のではなく「良い写真を見つけて、その上に情報を重ねる」という考え方がデザインの近道になることを、この課題で体感しましょう。

事前準備

  • Canvaにログインしている
  • お手本の画像を、上のセクション1でいつでも見返せる状態にしている
  • Chapter 1で作成した「Canva_練習」フォルダを開ける状態にしている

模写の手順

1カスタムサイズの新規デザインを作成する
  1. Canvaのホーム画面で「デザインを作成」ボタンをクリックする
  2. 表示されたメニューから「カスタムサイズ」を選ぶ
  3. 幅に「1920」、高さに「1080」を入力し、単位が「px」になっていることを確認する
  4. 「新しいデザインを作成」ボタンをクリックする
2背景に室内写真を配置する
  1. 左メニューの「素材」タブを開く
  2. 検索欄に「部屋 インテリア」などのキーワードを入力して検索する
  3. お手本に近い、明るくナチュラルな雰囲気の写真をクリックしてキャンバスに追加する
  4. 写真の四隅のハンドルをドラッグして、キャンバス全体を覆う大きさまで拡大する
3半透明の情報エリアを重ねる
  1. 左メニューの「素材」→「図形」から四角形を選び、画面左側にドラッグして配置する
  2. 図形を選択したまま、上部ツールバーの色アイコンをクリックし、白またはベージュ系の色を選ぶ
  3. 同じ図形を選択したまま、上部ツールバーの透明度アイコン（丸が重なったアイコン）をクリックする
  4. 表示されたスライダーを50〜70%程度までドラッグして下げる
4氏名のテキストを配置する
  1. 左メニューの「テキスト」タブを開き、「見出しを追加」をクリックする
  2. 追加されたテキストボックスに氏名（例：佐藤 はるみ）を入力する
  3. 上部ツールバーのフォント名をクリックし、検索欄で日本語フォントを検索して、太めのフォントに変更する
  4. 同じ手順でもう1つテキストボックスを追加し、氏名の下に英字名（例：Harumi Sato）を小さめのサイズ・斜体系フォントで入力する
5点線バッジと自己紹介文を作る
  1. 「素材」→「図形」から円を選び、半透明エリアの上に配置する
  2. 円を選択したまま、上部ツールバーの線のアイコンをクリックする
  3. 線の種類で「点線」を選び、太さを細めに設定する
  4. 円の中をダブルクリックしてテキストを追加し、短い自己紹介文（例：WEBデザインを学んでいます）を入力する
✓ Point !
円の枠線を点線にする方法

円を選択した状態で上部ツールバーの線のアイコンから、線の太さと種類（実線／点線／破線）を選べます。
お手本のような点線の丸バッジは、この設定だけで再現できます。

6「Follow me!」とQRコードを配置する
  1. 「テキスト」タブからテキストボックスを追加し、「Follow me!」と入力する
  2. 「素材」タブの検索欄に「QRコード」と入力して検索する
  3. 表示された標準のQRコード素材をクリックしてキャンバスに追加する
  4. ドラッグしてサイズと位置を整える
7顔用のスペースを空けておく
  1. 画面中央〜右側（自分の顔が写る想定範囲）には何も置かず空けておく
  2. 一通り配置し終えたら、キャンバス全体を見渡し、要素がその範囲にはみ出していないか確認する
! 注意
顔が写る範囲を空けておく

実際にビデオ通話で使う背景なので、画面中央〜右側には文字や図形を置かないようにしましょう。
お手本でもその範囲は完全に空けられています。

8保存してダウンロードする
  1. 右上の「共有」ボタンをクリックする
  2. 表示されたメニューから「ダウンロード」を選ぶ
  3. ファイルの種類で「PNG」を選択し、「ダウンロード」ボタンをクリックする
  4. ダウンロードしたファイルを「Canva_練習/03_output」に移動し、ファイル名をzoom-bg_v1.pngに変更して保存する
