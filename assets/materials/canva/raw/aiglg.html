新規デザインを作成する

まずは、新しいデザインを1つ作成するところから始めましょう。
ダッシュボード画面右上の「デザインを作成」ボタンをクリックすると、あらかじめ用意されたサイズ（Instagram投稿・プレゼンテーションなど）の候補が一覧表示されます。
決まったサイズが無い場合は、「カスタムサイズ」から好きな幅・高さを直接指定することもできます。

サイズを選ぶ（または空白のデザインを選ぶ）と、空白のキャンバスが開きます。
今回は練習として、空白のデザインを1つ作成しましょう。この後のテキスト・素材の操作は、すべてこの空白のキャンバスから始めます。

✓ Point !
サイズはあとから変更できる

作成時に選んだサイズは、あとからでも変更できます。
まずは大まかなサイズで作り始めて、必要になったタイミングで調整する、という進め方で問題ありません。

テキストを入力する

デザインが開いたら、テキストボックスをキャンバスに追加し、文字を入力したら、太字・斜体・下線・打消し線などの装飾や、フォントの種類・サイズを自由に変更できます。

✓ Point !
操作を間違えたら元に戻す

操作を間違えたときは、画面左上の「↺（元に戻す）」を押せば直前の操作を取り消せます。
逆に戻しすぎたときは、隣の「↻（やり直す）」で戻せます。
失敗を恐れず、どんどん操作して試してみましょう。

✓ Point !
有料フォントの見分け方

フォント一覧で👑（王冠マーク）がついているものは有料版限定のフォントです。
無料版で作業するときは、王冠マークがついていないフォントを選びましょう。

素材を配置する

次に、写真・図形・イラストなどの素材をキャンバスに追加する操作です。
左側のパネルから素材を検索し、クリックまたはドラッグでキャンバスに配置します。
気に入った素材はお気に入り登録しておくと、次回すぐに使えて時短になります。

操作 できること
素材の色変更 図形や一部のイラストは、クリックするとカラーパレットが表示され色を変更できる（表示されない素材は色変更不可）
画像アップロード PCに保存した画像・動画をアップロードして、自分の素材として使える
写真編集 色味・明るさをキャンバス上で調整できる

図形を追加する

四角形・円・線などの基本図形も、写真やイラストと同じ素材パネルから追加できます。
パネルの「図形」カテゴリを開き、使いたい図形をクリックするだけでキャンバスの中央に追加されます。
追加した図形は、これまでと同じようにドラッグで移動したり、ハンドルで拡大・縮小したりできます。

✓ Point !
図形はロゴ代わりにも使える

お手本にちょうど合うイラストが見つからないときは、シンプルな図形（円・四角形など）を組み合わせるだけでも、ロゴや装飾として十分に見た目が整います。

✓ Point !
同じ要素を複製できる

要素を選択すると、右上に「複製」アイコンが表示されます。
これをクリックすると、同じ要素をもう1つ増やせます。同じ図形を繰り返し使いたいときは、毎回作り直さずに複製すると時短になります。

色を変更する

テキスト・図形・背景の色は、それぞれ同じような手順で変更できます。
色を変えたい要素をクリックして選択し、上部ツールバーに表示される色のスウォッチ（四角いアイコン）をクリックすると、カラーパレットが開きます。
背景色を変えたいときは、何も選択していない状態にすると、同じように背景色のスウォッチが表示されます。

✓ Point !
配色を真似るコツ

お手本と同じ色に近づけたいときは、カラーパレット下部の「＋」から16進数のカラーコード（例：#FF0000）を直接入力すると、目分量よりも正確に色を合わせられます。

移動・拡大縮小・レイヤー操作

配置した要素は、ドラッグまたは矢印キーで位置を調整し、四隅のハンドルで拡大・縮小できます。
複数の要素が重なったときは、レイヤー（重ね順）を操作して前後関係を整理します。

✓ Point !
レイヤーの重なりで見た目が決まる

テキストが画像の後ろに隠れてしまう、といったトラブルはレイヤーの前後関係が原因です。
要素を右クリック（または上部メニュー）から「レイヤーを最前面へ」「最背面へ」を選んで調整しましょう。

配置を揃える

複数の要素をきれいに整列させるには、配置機能を使います。
要素を選択した状態で、左揃え・右揃え・中央揃え（横方向）、上揃え・中央揃え・下揃え（縦方向）を選ぶだけで、手作業では難しいピクセル単位の整列が一瞬でできます。
また、「均等配置」を使うと、複数の要素の間隔を均等にそろえることもできます。

Q
確認クイズ
複数の要素の横位置をきれいに真ん中に揃えたいとき、使うべき機能は？
✓
正解です！
配置機能の中央揃えを使えば、目分量ではなく正確に真ん中へ整列できます。
✕
惜しい！
正解は「配置機能の中央揃え」です。レイヤー操作は前後関係、お気に入り登録は素材の保存に使う機能です。
SUMMARY
  1. 新規デザインは「デザインを作成」ボタンからサイズを選ぶ（またはカスタムサイズを指定）だけで作成できる
  2. テキストは入力後、装飾・フォント種類・サイズを自由に変更できる（👑マークは有料フォント）
  3. 素材は検索して配置、お気に入り登録、PCからのアップロードができる
  4. 図形は素材パネルの「図形」カテゴリから追加できる
  5. テキスト・図形・背景の色は、要素を選択して色スウォッチから変更できる
  6. 要素の重なりはレイヤー操作で前後関係を整理する
  7. 複数要素の整列は配置機能（左右揃え・上下揃え）で正確に揃えられる
