ようこそ、Canvaへ

このレッスンには、操作も手順もまだ登場しません。
このコースを終えたときに、あなたが何を作れるようになっているのか、その全体像を先につかんでおくためのレッスンです。

Canvaは、豊富なテンプレートと素材を使いながら、誰でも直感的にデザインを形にできるツールです。
このコースでは、Canvaの基本操作から、お手本を真似て作る練習、そして依頼内容をもとに自分でゼロから仕上げる実践制作まで、順を追って学んでいきます。

✓ Point !
7割で動かすペースを身につける

「完璧にやろう」と力みすぎないこと。
これがこのコースの成果を大きく左右します。
まずは7割の完成度で手を動かしてみる。
このリズムが、コース全体を貫く基本姿勢です。

このコースで作れるようになるもの

まず、コースを通してどんなものが自分の手で作れるようになるのか、具体的にイメージしておきましょう。

フェーズ 制作物 ねらい
①模写フェーズ Zoom背景・名刺・SNS投稿（計3点） お手本を見ながら再現し、Canva操作に慣れながら「作れた」を積み重ねる
②実践制作フェーズ SNS広告バナー・チラシ・Instagram投稿・総合演習2媒体（計4〜5点） 架空企業の依頼書をもとに、Canva AI（Canva内のAI機能）も使いながら自力で仕上げる

模写3点＋オリジナル制作4〜5点、あわせて7〜8点の制作物が、コースを進めるうちに完成していきます。

✓ Point !
最初は真似ることから

いきなり「オリジナルで自由に作ってください」と言われても、何から手をつけていいか分からないのが普通です。
だからこのコースは、まずお手本を模写することから始めます。
真似る中で操作を覚え、そのあとで自分の力で作る実践制作に進みます。

このコースが目指すゴール

ここで一つ、大切なことを確認しておきます。

このコースのゴールは、Canvaの機能をすべて覚えることではありません。

多くの人は「ツールを完璧に使いこなせるようになってから作品を作ろう」と考えがちです。
ところが、その考え方だと、いつまで経っても「まだ準備が足りない」と感じて手が止まってしまいます。

このコースでは、手を動かしながら、実際に完成させる経験を積み重ねることで学べるようになっています。

✓ Point !
「作れた」という経験の積み重ねを目指す

コースの終わりに完璧なデザイナーになる必要はまったくありません。
模写もオリジナル制作も、実際に最後まで完成させた経験がある状態。
これがこのコースのゴールです。
腕前は、そのあと作り続けるうちに自然と磨かれます。

Chapter 0〜3の学習の流れ

コース全体がどんな流れで進むのか、先に見ておきましょう。

Chapter 内容 この段階でできるようになること

✓ Point !
段階を踏むから、無理なく前に進める

いきなり実践制作から始めるわけではありません。
基本操作 → 模写 → 実践制作と、少しずつ難易度を上げる設計になっています。
今の自分がどの段階にいるかを意識しながら進めれば、迷わず前に進めます。

SUMMARY
  1. コースを終えると、模写3点＋オリジナル制作4〜5点＝計7〜8点の制作物が完成している
  2. このコースが目指すのはツールの完全習得ではなく、「作れた」という成功体験
  3. 完璧を目指さず、まず7割で動かして改善するのが正解のペース
  4. 学習は基本操作 → 模写 → 実践制作の順で、少しずつ難易度が上がっていく
