Canvaとは何か

Canvaは、ブラウザ上で使えるグラフィックデザインツールです。
世界中のクリエイターが制作したテンプレートと、豊富な写真・イラスト・動画素材があり、ドラッグ＆ドロップの操作で名刺・チラシ・SNS投稿・ポスターなど、あらゆるデザインを作成できます。

専門的なデザインソフトと違って操作が直感的なので、デザインツールに初めて触れる人でも扱いやすいのが特徴です。
このコースでは、このCanvaを使って模写制作と実践制作を進めていきます。

✓ Point !
まず触ってみる精神で

Canvaは説明を読むよりも、実際に触ってみたほうが理解が早いツールです。
「とりあえず触ってみる」精神で、次のレッスンから手を動かしながら覚えていきましょう。

無料版と有料版の違い

Canvaには無料版と有料版（Canva Pro）があります。
有料版にすると使える素材・テンプレート・フォントの種類が大幅に増えますが、このコースの演習はすべて無料版の範囲内で完結できるように設計されています。
まずは無料版から始めましょう。

項目 無料版 有料版（Canva Pro）
テンプレート・素材 一部利用可能。このコースの演習には十分な種類がある プレミアム素材・テンプレートが大幅に増える
背景透過ダウンロード 不可 PNG形式で背景透過して書き出せる
フォント 一部利用可能 すべてのフォントが利用可能
✓ Point !
案件では有料版が必要になる場面もある

学習中は無料版で十分ですが、実際の案件では「背景透過PNGで納品してほしい」「プレミアム素材を使いたい」という場面が出てきます。
まず無料版で操作を覚え、必要になったタイミングで有料版を検討するという判断基準を持っておきましょう。

アカウントを準備する

それでは、実際にCanvaのアカウントを作成しましょう。
Googleアカウントまたはメールアドレスがあれば、数分で登録が完了します。

ボタンを押すと、登録方法の選択画面が表示されます。Googleアカウント・Yahoo! JAPAN ID・Facebook・メールアドレスのいずれかを選べます。
普段使っているGoogleアカウントがあれば、それを選ぶのが一番早く済みます。

✓ Point !
登録後に確認画面がいくつか続く

登録が完了すると、「利用目的の選択」「メール配信設定」「AIによるコンテンツ活用の許可」など、いくつか確認画面が続けて表示されます。
ここでは特に迷いやすい2つだけ取り上げます。それ以外の画面の細かい操作は、動画のほうで実際の流れを通しで確認してください。

✓ Point !
登録の流れ（まとめ）
  1. Canva公式サイトにアクセスし、「登録」ボタンを押す
  2. Googleアカウントまたはメールアドレスで登録する
  3. 利用目的を聞かれたら「個人的なプロジェクト」を選択する
  4. AIの学習活用は、不安であればオフのままでよい
  5. ダッシュボード画面が表示されたら準備完了
