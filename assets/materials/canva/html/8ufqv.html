完成イメージを確認する

模写フェーズ最後の課題はSNS投稿です。
今回は1枚completeではなく、表紙＋本文ページ2枚、計3枚のInstagramカルーセル投稿を作ります。
本文ページは同じデザインテンプレートを使い回し、見出し・写真・説明文だけを差し替えているのがポイントです。要素の重なり順とテンプレートの使い回し方を意識しながら、お手本と同じになるように仕上げてみましょう。

使う要素を分解する

このお手本は「表紙」と「本文ページ」で層構成が異なります。まずは表紙から、下から上に向かって次の順番でレイヤーが重なっています。

重なり順 要素 内容
① 一番奥 写真 PC作業中の手元の写真を、ぼかしフィルターをかけてキャンバス全体に配置
② その上 カラーオーバーレイ 紫〜ティールの図形に透明度を付けて、写真の上に重ねる
③ さらに上 白の一本線フレーム 内側に余白を持たせた、細い線の四角
④ 一番手前 タグ・タイトル・アカウント名 タグ「＼初心者さんにおすすめ／」、大きな2行タイトル、下部のアカウント名

一方、本文ページは表紙で使った要素を再利用した構成です。写真とタグを外し、カラーオーバーレイと枠の見た目だけを変えて使い回します。

配置順 要素 内容
① 一番奥 グラデーション背景 表紙のカラーオーバーレイを再利用。透明度をなくして不透明にし、そのままキャンバス全体の背景にする
② その上 白いカード 表紙の一本線フレームを再利用。塗りを白・角を丸く変えて、内側に余白を持つ白いカードにする
③ さらに上 装飾ライン＋見出し 星アイコンと短い一本線の装飾、その下に機能名の見出し
④ さらに上 テーマ写真 紹介する機能のイメージに合う正方形の素材写真
⑤ 一番手前 説明文 その機能の使い方・メリットを2〜3行で簡潔に説明
✓ Point !
重なり順とテンプレートの使い回し

表紙は写真→オーバーレイ→枠→テキストの順で、下の層から順番に配置していくと迷いません。
本文ページは、表紙のカラーオーバーレイと枠をそのまま活かし、見た目（透明度・塗り・角の丸み）だけを変えて背景とカードに転用するのがポイントです。
1ページ作ったら複製し、見出し・写真・説明文だけを差し替えれば、レイアウトを毎回作り直さずに複数ページを揃えられます。

模写の手順

11080×1080pxの新規デザインを作成する
  1. 左上の「作成」ボタンを押し、デザインの種類の一覧を開く
  2. 一覧に表示される「Instagram投稿」テンプレートはサイズが4:5（正方形ではない）なので使わず、「カスタムサイズ」を選ぶ
  3. 単位を「px」にし、幅と高さにそれぞれ「1080」を入力する
  4. 「新しいデザインを作成」ボタンをクリックする
2背景写真を配置する
  1. 左メニューの「素材」タブを開き、検索欄に「パソコン」「作業」などのキーワードを入力する
  2. お手本に近い写真を選び、キャンバスにドラッグして配置する
  3. 四隅のハンドルをドラッグし、写真がキャンバス全体を覆うサイズまで拡大する
  4. 「配置」から中央揃えを選び、キャンバスの中央にぴったり合わせる
3カラーオーバーレイを重ねる
  1. 背景の写真を選択し、上部ツールバーの透明度アイコンから透明度を60%程度まで下げる
  2. 「素材」→「図形」から四角形を選び、キャンバス全体を覆うサイズに拡大する
  3. 図形を選択したまま塗りの色アイコンを押し、紫系の色に変更する
  4. 同じ図形にグラデーションを適用し、紫からティール（青緑）へのグラデーションに変更する
  5. 図形の透明度アイコンから透明度を下げ、下の写真がうっすら透けるくらいに調整する
4一本線の枠を配置する
  1. もう一度「図形」パネルを開き、通常の四角形を配置する
  2. 上部ツールバーの塗りの色を押し、塗りつぶしを「透明」に変更する
  3. 線の太さのアイコンから1〜2ピクセル程度の細めの設定を選び、線の色のアイコンから枠線の色を白に変更する
  4. 四隅のハンドルをドラッグして、キャンバスの端から少し内側に入った位置、上下左右に均等な余白ができるサイズに調整する
  5. 上部ツールバーの「配置」から、キャンバスのちょうど中央に来るよう位置を揃える
5タグを作る
  1. 「素材」→「図形」から角丸の四角形を選び、左上あたりに小さく配置する
  2. 図形を選択したまま塗りの色を紫に変更する
  3. 上部ツールバーの角丸設定から丸みの強さを調整する
  4. 「テキスト」タブからテキストボックスを追加し、「＼初心者さんにおすすめ／」と入力して図形の上に重ねる
  5. テキストの色を白に変更し、図形の中央に配置する
6タイトルとアカウント名を配置する
  1. 「テキスト」タブから見出しスタイルのテキストボックスを追加する
  2. フォントをセリフ体に変更する
  3. 「Canva」「オススメ機能」の2行に分けて大きめのサイズで中央に配置する
  4. 一番下に小さめのテキストで「@webcoach」を追加する
7本文ページ用に複製・背景を整える
  1. 表紙ページのサムネイルを右クリックし、「複製」を選んで2ページ目を作る
  2. 複製したページから、写真とタグ（角丸四角形＋テキスト）を選択して削除する
  3. カラーオーバーレイの図形を選択し、透明度を100%（不透明）に戻す
  4. 白い一本線の枠を選択し、塗りの色を白に変更して線を消す
  5. 上部ツールバーの「角丸設定」を選び、角を丸くする
8装飾ラインと見出しを配置する
  1. 「素材」タブで星のアイコンを検索し、カードの上部中央に配置する
  2. 星を複製し、色とサイズを星に合わせた短い一本線を左右に1本ずつ配置する
  3. 「テキスト」タブから見出し用のテキストボックスを追加し、「テンプレート機能」と入力する
  4. テキストを選択したまま、フォントと文字色を変更する（文字色は紺色（ネイビー）に設定）
  5. この本文ページ1枚目を、以降の本文ページの基本テンプレートにする
9テーマ写真と説明文を配置する
  1. 見出しの下に「素材」タブから紹介する機能のイメージに合う写真を配置する
  2. 写真をクリックし、表示される「トリミング」を選ぶ
  3. トリミングモードで写真をドラッグし、見せたい範囲だけを枠内に収める
  4. 「適用」を押してトリミングを確定する
  5. 上部ツールバーの角丸設定から、写真の角を丸くする
  6. 写真の下にテキストボックスを追加し、その機能の使い方やメリットを2〜3行程度で入力する
10もう1枚複製して内容を差し替える
  1. 本文ページ1枚目のサムネイルを右クリックし、「複製」を選んでもう1枚作る
  2. 見出しのテキストをダブルクリックし、別の機能名（例：「カラーパレット機能」）に書き換える
  3. 写真をクリックして表示される「置き換え」ボタンを押す
  4. 検索欄に新しいキーワードを入力し、表示された写真をクリックして差し替える（位置・サイズ・角丸はそのまま保たれる）
  5. 説明文をダブルクリックし、新しい機能に合わせた内容に書き換える
11お手本と見比べて微修正する
  1. 1ページ目（表紙）を確認し、写真・グラデーション・白い枠・タグ・タイトルの組み合わせを見比べる
  2. 2・3ページ目（本文ページ）を確認し、レイアウトが同じまま内容だけ差し替わっているかを見比べる
  3. 色味・文字の大きさ・要素の位置にズレがあれば、この段階で微調整してお手本に近づける
12保存してダウンロードする
  1. 画面右上の「共有」ボタンを押す
  2. 表示されたメニューから「ダウンロード」を選ぶ
  3. ファイルの種類の一覧から「PNG」を選択する
  4. 「ダウンロード」ボタンを押すと3ページ分の画像がまとめて書き出される（複数ページは自動的にZIP形式にまとめられる）
  5. ダウンロードしたファイルを「Canva_練習/03_output」に移動して保存する
