完成イメージを確認する

今回は表裏2面ある名刺を模写します。
表面は氏名だけのシンプルな「顔」、裏面は連絡先をまとめた「実用面」という役割分担になっています。できるだけお手本と同じ配置・配色・要素になるように仕上げてみましょう。

! 注意
このレッスンで躓きやすいポイント

名刺サイズ（91×55mm）は小さいため、テキストサイズを上げすぎるとはみ出します。
お手本の文字の大きさをよく見て、近いサイズから調整しましょう。

事前準備

  • Canvaにログインしている
  • お手本の表裏画像を、上のセクション1でいつでも見返せる状態にしている
  • Chapter 1で作成した「Canva_練習」フォルダを開ける状態にしている

模写の手順

1名刺サイズの新規デザインを作成する
  1. Canvaのホーム画面で「作成」→「カスタムサイズ」を選ぶ
  2. 単位を「mm」に変更する
  3. 幅に「91」、高さに「55」を入力する
  4. 「新しいデザインを作成」ボタンをクリックする
  5. 1ページ目を表面、2ページ目を裏面として使うため、下部の「＋ページを追加」でページを2枚にする
2表面を作る
  1. 背景色をごく薄いピンクに変更するか、左メニューの「素材」タブで「水彩 背景」を検索して敷く
  2. 「素材」→「図形」から四角形を選び、内側に余白を持たせたサイズでキャンバス中央に配置する
  3. 図形を選択したまま、上部ツールバーの色アイコンをクリックし、塗りつぶしを「透明」に変更する
  4. 同じ図形を選択したまま、線のアイコンから枠線の太さを0.5・色をグレーに設定する
  5. 「素材」タブで「リボン」または「蝶結び」を検索し、上部中央に小さく配置する
  6. 「テキスト」タブから肩書「Web designer」を控えめなサイズで追加し、中央揃えにする
  7. 同じ手順で氏名「Sato Harumi」をセリフ体フォント・大きめのサイズで肩書の下に追加し、中央揃えにする
✓ Point !
文字色に真っ黒は使わない

テキストの色は#000000の真っ黒ではなく、少しやわらかいダークグレー系の色を選びましょう。
真っ黒は背景との対比が強すぎて、上品な水彩背景の雰囲気と合いません。

3裏面を作る
  1. 1ページ目のサムネイルを右クリックし、「複製」を選んで2ページ目を作る（背景色・水彩背景がそのまま引き継がれる）
  2. 複製したページから、リボン・肩書・氏名のテキストを選択して削除する
  3. 「素材」タブで気に入った素材を1点選び、キャンバス左側に配置する（写真・イラストなど種類は問わない）
  4. 写真を選択した状態で上部ツールバーの「フレーム」から円形のフレームを選び、写真を円形にトリミングする
  5. 写真の右に、「テキスト」タブから肩書（明朝系フォント・控えめ）を追加する
  6. 同じ手順で氏名（明朝系フォント・大きめ）を肩書の下に追加する
4連絡先とQRコードを配置する
  1. 「素材」タブで電話・メール・WEBのアイコンをそれぞれ検索し、縦に3行並べる
  2. 各アイコンの右にテキストボックスを追加し、電話番号・メールアドレス・WEBサイトURLを入力する
  3. 右下に「Instagram →」のテキストを追加する
  4. 「素材」タブの検索欄に「QRコード」と入力し、表示された標準のQRコード素材をクリックして配置する
5保存してダウンロードする
  1. 右上の「共有」ボタンをクリックする
  2. 表示されたメニューから「ダウンロード」を選ぶ
  3. ファイルの種類で「PNG」を選択し、「ダウンロード」ボタンをクリックする
  4. ダウンロードしたファイルを「Canva_練習/03_output」に移動し、ファイル名をmeishi_v1.pngに変更して保存する（2ページとも書き出される）
Q
確認クイズ
お手本のような丸型プロフィール写真を作りたいとき、使う機能は？
✓
正解です！
フレーム機能を使うと、写真を円や好きな形に切り抜いて配置できます。名刺の丸型プロフィール写真もこの機能で作れます。
✕
惜しい！
正解は「フレーム機能」です。写真を丸や好きな形に切り抜くときに使います。
✓ Point !
仕上げに、お手本と見比べよう

一通り作成できたら、それで終わりにせず、お手本の画像とキャンバスを並べて見比べてみましょう。
色味・文字の大きさ・要素の位置など、ズレている箇所があれば、ダウンロードする前に微調整して、できるだけお手本に近づけます。
この「見比べて整える」工程が、模写の仕上がりを大きく左右します。
