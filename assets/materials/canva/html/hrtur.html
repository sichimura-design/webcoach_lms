上達は試行錯誤の繰り返し

最初に大事なことを伝えます。

Canvaでのデザイン制作は、もともと手を動かしながら試行錯誤を重ねることが上達の前提です。
一度作っただけで完璧なデザインに辿り着く人はいません。
プロでも、何度も配置を直したり配色を変えたりしながらクオリティを上げていきます。

Chapter 3で使うCanva AI（Canva内のAI機能）も同じです。
一発で理想の結果を出すのは難しいと理解してください。
試す → 観察する → 調整する、この繰り返しが標準の作業フローです。

✓ Point !
試行錯誤こそスキルを育てる
  1. うまくいかないときは改善のヒント：デザインがイメージ通りに仕上がらなかったとき。それは失敗ではなく、改善すべき点が見えているとポジティブに捉えましょう。
  2. つまずくほど、判断力とツールの使い方の精度が上がる：なぜ期待通りにならなかったかを考えて修正するたびに、デザインを見る目も操作の精度も伸びていきます。

完璧主義を捨てる — 7割の法則

「もう少し練習してから」と待ち続けると、次のレッスンにいつまでも進めません。
7割の完成度で次へ進むのがこのコースの正しいペースです。
学習が進んでスキルがついてきたら、そのタイミングで過去の制作物に戻って修正すれば十分です。
動かしながら磨くほうが、結果として成長は速くなります。

「わからなくて当然」という許可を自分に与える

初心者のうちは「こんなこともわからないなんて」と自分を責めたくなることがあるかもしれません。
でも、わからなくて当然です。
このコースにいる全員が、最初はゼロからスタートしています。

✓ Point !
進むか迷ったら、この3つを自分に問う

「もう少しブラッシュアップしたい」と感じて手が止まったら、次の3つを順番に確認してみてください。

  1. 「今の状態で、一旦完成として提出できるか？」　→ Yesなら、もう"完成"していい段階。
  2. 「完璧にするためにあと何時間かかるか？」　→ 数字で答えられないなら、終わりが見えない作業に入っているサイン。
  3. 「その時間で次のレッスンを進めたら何が得られるか？」　→ 得られるものが大きいなら、進んだ方が成長が早い。
SUMMARY
  1. Canva学習は試行錯誤が標準。1回でうまくいかないのは当然であり、成長のプロセス
  2. 7割の完成度で次へ進むことが、コースを完走する速度を決めるポイント
  3. 「わからなくて当然」という許可を自分に与える
CHECK
理解度チェック
Canva学習で「試行錯誤」が前提である理由を説明できる
デザインはもともと、手を動かしながら配置や配色を試して上達していくものです。Canva AIでも同じで、一発で理想の結果を出すのは難しいため「試す→観察→調整」のサイクルが標準の作業フローになります。
「7割で動かす」ことが重要な理由を説明できる
完璧を待ち続けると学習が止まってしまいます。残りの3割は経験を積む中で埋まります。まず動かすのが最速の上達ルートです。
