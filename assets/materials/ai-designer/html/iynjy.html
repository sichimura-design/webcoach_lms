クライアントへの納品は、プロのデザイナーにとってもっとも責任が問われる場面です。納品前に必ず通すべき3つのチェック（逆画像検索・仕上げ前の最終チェック・ファイル整理）を順に押さえます。

逆画像検索の最終確認

制作した画像すべてで逆画像検索を済ませているか確認しましょう。もしやっていない画像があれば、納品前のこのタイミングで忘れずに実施してください。

Googleトップ画面の検索バー右端のカメラアイコンから画像をアップロードし、著名な商業作品や写真素材と酷似していないかを目視確認します。類似が強く出た画像は、プロンプトの特定スタイル指定（〇〇風など）を削除して再生成してから納品します。

なお、Googleは全著作物をカバーしているわけではないため、検索結果に出なかったから絶対に安全、とは言い切れません。明らかな類似を事前に排除するためのチェックと位置づけてください。

仕上げ前の最終チェック（2-6 再掲）

2-6 で学んだ「仕上げ前の最終チェック」を、納品前にもう一度通します。テキスト配置5項目と修正漏れ4項目の合計9項目です。1つでも引っかかれば修正してから納品してください。

テキスト配置チェック（5項目）

チェック項目 確認内容
①揃え方の統一 左揃え・中央揃えが混在していないか確認する。意図的でないかぎり、同じグループ内のテキストは揃えを統一する
②端からの余白 テキストがデザインの端ギリギリに配置されていないか確認する。端から20〜30px以上の余白があると視覚的に安定する
③優先順位の視覚化 キャッチコピー ＞ サブコピー ＞ 詳細テキストの順に、フォントサイズと太さで差がついているか確認する
④レイヤー順序 テキストが被写体やオブジェクトに隠れていないか確認する。テキストレイヤーが画像レイヤーの裏に入っていないかチェックする
⑤内容の誤り 誤字脱字・価格・キャンペーン期間・連絡先など、数字や固有名詞を依頼書と照合して確認する

修正漏れチェック（4項目）

チェック項目 確認内容
①フォント数 2種類以内に収まっているか確認する。見出し用・本文用の2種類を超えると統一感がなくなる
②使用色数 3〜4色以内に収まっているか確認する。メインカラー・アクセントカラー・テキストカラーの組み合わせを絞るほど、まとまりが出る
③ロゴ・ブランド要素 クライアントから提供されたロゴ画像が正しく配置されているか確認する。ChatGPT Images 2.0ではロゴを生成しないため、必ずCanvaで後から追加する
④文字化けの再確認 Magic Layers適用後に見落としていた文字化けがないか、全テキストをよく確認する
✓ Point !
カルーセル5枚は1枚ずつ通す

Instagramカルーセル5枚は、1枚目から5枚目まで 1枚ずつ独立してテキスト配置5項目＋修正漏れ4項目を通します。ページごとに役割が違うので、見落としが起きやすい点に注意してください。

ファイル命名・フォルダ整理

ファイル名にバージョン番号を入れることだけが必須ルールです。修正依頼が来たとき、元ファイルを残した状態で_v2を作れるようにしておきます。

✓ Point !
印刷物は2形式を必ず保存

チラシなど印刷物は、印刷用PDF（トリムマーク・塗り足しオン）とポートフォリオ用PNGの2形式を保存する習慣をつけてください。foriioやSNS掲載にはPNGを使います。

納品前の最終チェック（3項目）

  • 制作した全画像について逆画像検索を実施した
  • 仕上げ前の最終チェック（2-6 再掲・テキスト配置5項目＋修正漏れ4項目）をもれなく通した
  • ファイル名にバージョン番号（_v1）を入れ、印刷物はPDF + PNGの2形式で保存、フォルダ整理が完了している
SUMMARY
  1. 納品前チェックは逆画像検索の最終確認・仕上げ前の最終チェック再掲・ファイル整理の3項目
  2. 逆画像検索は制作した画像すべてで済ませているかを納品前にもう一度確認する
  3. 2-6 で学んだテキスト配置5項目＋修正漏れ4項目を、納品前にもう一度通す
  4. カルーセル5枚は1枚ずつ独立して同じ9項目チェックを通す
  5. ファイル名にバージョン番号（_v1）をつけることが、修正依頼に備える唯一のルール
  6. 印刷物はPDF + PNG の2形式を必ず保存する

理解度チェック
納品前チェックの3項目を言える
①逆画像検索の最終確認（全画像で実施済みか）／ ②仕上げ前の最終チェック（2-6 再掲・テキスト配置5項目＋修正漏れ4項目）をもれなく通す ／ ③ファイル整理（命名規則・バージョン番号・フォルダ分類）の3項目です。
2-6 で学んだ「仕上げ前の最終チェック」の項目構成を言える
テキスト配置5項目（揃え方の統一・端からの余白・優先順位の視覚化・レイヤー順序・内容の誤り）と、修正漏れ4項目（フォント数・使用色数・ロゴ配置・文字化け）の合計9項目です。納品前にもう一度通します。
ファイル管理で唯一必須のルールを説明できる
ファイル名に_v1・_v2などのバージョン番号をつけることです。フォルダ名やファイル名の形式は自分が管理しやすいものでよいですが、バージョン番号は修正依頼に備える唯一のルールです。
印刷物の書き出しで保存する2形式を説明できる
印刷用PDF（トリムマーク・塗り足しをオンにしたもの）とポートフォリオ用PNGの2形式です。納品時はPDF、foriioやSNS掲載時はPNGを使うので、両方を保存する習慣をつけます。
