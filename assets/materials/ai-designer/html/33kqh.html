ツールと費用の確認

このコースではChatGPTとCanvaの2つを使用します。最初の1ヶ月は基本的に両方とも無料で進められます。1ヶ月経過したタイミングで、解約・別プランへの切り替え・課金継続のいずれかを判断してください。

ツール 推奨プラン 月額費用 選ぶ理由
ChatGPT Plus / Go 初月0円（無料トライアル）
2か月目以降
Plus: ¥3,000／Go: ¥1,400		 初月は無料トライアルでPlusが使用できる。2か月目以降はPlusをそのまま継続するか、Goプランへ移行、解約のいずれかを選ぶ
Canva Pro 初月0円（無料トライアル）
2か月目以降
¥1,180		 AI機能を安定して活用するためProを推奨
! 注意
解約忘れに気をつけてください

ChatGPT Plusの1か月無料トライアル終了後は自動で月額¥3,000、Canva Proの30日間トライアル終了後は自動で月額¥1,180の課金が始まります。続けない場合・安価なGoプラン（¥1,400/月）に切り替える場合は、スマホのリマインダーにそれぞれの終了日をセットしておきましょう。

✓ Point !
ツールの無料トライアルが出てこないときは？

ChatGPTもCanvaも、無料プランのままでも教材は問題なく進められます。ただし無料プランは生成回数などに制限がつくため、一気に進めたい方やより効率的に学習したい方は、有料プランへの加入を検討してください。

学習用Googleアカウントの作成

ChatGPT Plusの無料オファーは、以前から使っているGoogleアカウントで登録すると表示されないことがあります。まず学習用に新しいGoogleアカウントを作成してから、ChatGPTのセットアップに進んでください。

✓ Point !
学習用Googleアカウントの作成手順
  1. Google Chromeを開き、右上のプロフィールアイコンから「追加」をクリック
  2. ログイン画面が表示されたら「アカウントを作成」をクリックし、案内に従って登録を完了する

ChatGPTのセットアップ

まずPlus 1か月無料トライアルを有効にして、画像生成が動作することを確認します。

✓ Point !
ChatGPTセットアップの手順
  1. chatgpt.com にアクセスしてログイン（上記で作成した学習用Googleアカウントを使用）
  2. 左下のアカウント名 → 「無料で Plus を試す」 をクリック
  3. Plus 1か月無料トライアル画面の 「無料オファーを受け取る」 をクリック
    ※新しいアカウントでないと無料オファーが出てこないことがあります
  4. クレジットカード情報を入力して登録を完了（初月0円・2か月目以降¥3,000を自動請求）
  5. 「猫のイラストを描いて」と送信
  6. 画像が生成されれば ChatGPT Images 2.0 が使える状態

演習では依頼書の内容をそのままChatGPTに貼り付けて使ってOKです。貼り付けたあと、自分で追加したい情報（雰囲気・ターゲット・スタイルなど）を補足してから送信します。プロンプト全文を一度に組み立てる必要はありません。

学習データをOFFにする手順（ChatGPT）

クライアントの資料や未公開素材をアップロードする前に、以下の4ステップで設定を変更してください。一度設定すれば、以降ずっと有効です。

✓ Point !
学習データOFF設定の手順
  1. ChatGPT画面の左下のアカウント名をクリック
  2. メニューから「設定」を選択
  3. 左メニューの「データコントロール」をクリック
  4. 「全員のモデル改善に役立てる」のトグルをクリックしてグレーにし、「実行する」ボタンをクリックして設定を完了する

Canvaのセットアップ

Canva Proにアップグレードして、プランが有効になっていることを確認します。

✓ Point !
Canva Proセットアップの手順
  1. canva.com にアクセスしてログイン
  2. 右上のアカウントアイコン → 「Canva Proを試す」 または 「プランをアップグレード」 をクリック
  3. Proプランを選択 → クレジットカード情報を入力（30日間無料トライアル。トライアル終了後に月額¥1,180の課金が始まります）
  4. 登録完了後、右上アカウントアイコン → 「設定」 をクリック
  5. 左メニューの 「課金とプラン」 を開き、Proプランが有効になっていることを確認する

確実な確認方法は「設定」→「課金とプラン」でプランの状態を直接見ることです。バッジ表示は環境によって出ないこともあるため、画面で直接確認するのが安全です。
