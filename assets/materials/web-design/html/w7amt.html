11章 選択範囲を使ってみよう

この教材の学習時間:180分

この章では、Photoshopを使用した画像編集において重要な機能である「選択範囲」の作成方法と使用方法を解説します。

【11-1】選択範囲とは

  • 「選択範囲」とは、画像内の部分的に選択されたエリアのことを指します。
    • 画像の一部分をコピーしたり、切り抜いて合成したり、フィルターや色調補正、彩色などの編集作業を部分的に行ったりする場合は、「選択範囲」を使用します。
  • Photoshopには、「選択範囲」を作成するための機能が多数用意されており、グラフィックの最終的な品質は、選択範囲をいかに美しく正確に作成できるかにかかっていると言っても過言ではありません。
  • 思い通りの画像編集・加工をすばやく行うためには、さまざまな選択範囲の作成方法に習熟し、状況に応じて、適切なツールを使い分けることができるようになる必要があります。

【11-2】さまざまな選択範囲の作成方法

長方形選択ツール

  • まずは、長方形選択ツールを使った画像の合成を行います。
  • 【11-1】の章でダウンロードした画像素材から、「長方形ツール1.jpg」と「長方形ツール2.jpg」を開いて下さい。
  • 下記2枚の写真を合成し、右の画像を作成していきます。
完成画像

制作手順

1. 長方形選択ツールを使い、写真をはめ込みたい部分に長方形の選択範囲を作成する

1. ツールパネルから「長方形選択ツール」を選択します。

2. 「長方形選択ツール1.jpg」のPC画面のディスプレイの左上の角から右下の角にかけてドラッグして下さい。
  • 長方形の破線の枠が表示されます。
    • この破線の枠内の領域を「選択範囲」と呼びます。
    • Photoshopの多くの編集機能は、この選択範囲の内側にしか適用されません。

長方形選択ツールのショートカットキー
  • 選択範囲を正方形に固定
    • Shiftキーを押しながら長方形選択ツールで斜めにドラッグすると、正方形の選択範囲を作成することができます。
  • 中心から選択範囲を描く
    • Optionキー（WindowsはAltキー）を押しながら長方形選択ツールで斜めにドラッグすると、四角形の中心から外側に広がるようにして選択範囲を作成することができます。

2. 水族館の写真を全て選択し、コピーする

1. 「長方形選択ツール2.jpg」のタブをクリックしてアクティブにして下さい。
  • この写真の全範囲を選択してコピーします。
    • 画像の全範囲を選択することを「すべてを選択」するといいます。
  • すべてを選択するためには、このように長方形の選択ツールで画像全体を外側から大きく囲むことで選択できます。

2. 画像の全範囲が選択できたので、この選択範囲に含まれる画像をコピーします。
  • ショートカットキーの⌘+C（WindowsはCtrl+C）でコピーして下さい。

ワンポイントアドバイス
  • 「すべてを選択」する際は、ドラックだけでなく、メニューバーの「選択範囲」から「すべてを選択」を選ぶことによっても、同様に「すべてを選択」することができます。
  • ⌘+A（WindowsはCtrl+A）というショートカットキーも覚えておくとよいでしょう。

3. 作成した選択範囲内にコピーした画像をペーストする

1. 「長方形選択ツール1.jpg」のタブをクリックしてアクティブにします。
  • 「編集」メニューから、「特殊ペースト」を選択。
  • 「選択範囲内へペースト」を選んで下さい。

2. 先ほどコピーした画像が、選択範囲の内側にはめ込まれるようにしてペーストされます。

4. はめ込んだ写真のサイズと位置を調整する

1. ツールパネルから「移動ツール」を選び、バウンディングボックスを使い、はめ込まれた画像のサイズを調整します。

2.  バウンディングボックスの角のつまみをドラッグして少しずつ縮小しながら、画像上をドラッグして位置の調整を行います。
※「環境設定」の「一般」で「従来の自由変形を使用」を選択している場合は、Shiftキーを押しながらドラッグすることにより、写真の縦横比が保持できます。

3. サイズと位置が決まったら、Return（Enter）キーで確定して合成写真の完成です。

バウンディングボックスとは？
  • バウンディングボックスとは、オブジェクトを選択した際に表示される、四隅と各辺の中央にハンドル（小さな四角）がついた枠のことです。
  • 「移動ツール」を選んだときにバウンディングボックスが表示されない場合は、オプションバーの歯車アイコンをクリックして、「バウンディングボックスを表示」にチェックを入れて下さい。
  • このバウンディングボックスを使うと、画像の拡大・縮小や回転などの変形操作が簡単にできます。

選択範囲の移動

作成した選択範囲を移動したいときは、その選択範囲を作成したツール、またはそれ以外の選択系のツールを使い、選択範囲の中をドラッグすると移動することができます。

楕円形選択ツールのショートカットキー
  • 選択範囲を正円形に固定
    • Shiftキーを押しながら楕円形選択ツールで斜めにドラッグすると、正円の選択範囲を作成することができます。
  • 中心から選択範囲を描く
    • Optionキー（WindowsはAltキー）を押しながら楕円形選択ツールで斜めにドラッグすると、正円形の中心から外側に広がるようにして選択範囲を作成することができます。

※ 移動ツールで選択範囲をドラッグすると、選択範囲内の画像が切り取られて移動してしまうので注意が必要です。

多角形選択ツール

  • 「多角形選択ツール」は多角形の選択範囲を作成するツールです。
  • クリックで多角形の頂点を作成し、最後に始点クリックすることにより、選択範囲が作成されます。
  • 今回は【11-1】の章でダウンロードした画像素材の中から、「多角形選択ツール.jpg」を用いて作業を行っていきます。

作成手順

4. ペーストした写真の四隅をドラッグして、ノートPC画面の四隅に合わせます。

5. Return（Enter）キーで確定して完成です。

マグネット選択ツール

  • 「マグネット選択ツール」は、マウスでなぞると 被写体の輪郭を自動判別して磁石のように吸着し、選択範囲を作成するツールです。
  • 被写体を囲み終わってから始点をクリックすると選択範囲が作成されます。

マグネット選択ツール：表示方法

画像素材：マグネット選択ツール.jpg

マグネット選択ツールのオプションバー

マグネット選択ツールはオプションバーで輪郭を検出する感度や精細度を設定することができます。

  • 幅：被写体の輪郭を検出する領域幅のこと。ここで指定したピクセル距離内でのみ輪郭を検知する。
  • コントラスト：被写体の輪郭を検知する感度の指定。数値が大きいほどコントラストの強い輪郭を検知する。
  • 頻度：境界を検出しながら吸着するポイントが作成される頻度のこと。数値が大きいほど吸着ポイントが増える。

クイック選択ツール

  • 「クイック選択ツール」は、被写体の内側をドラッグすると、境界線を自動で判別して選択範囲を作成するツールです。

クイック選択ツール：表示方法

画像素材：クイック選択ツール.jpg

作成手順

1. 「クイック選択ツール」で画像のTシャツ部分をドラッグすると、選択範囲が作成されます。

2. 一度できれいに選択できなくても、何回かドラッグを繰り返しながら選択範囲を追加していくことができます。
  • 選択したい部分から選択範囲がはみ出してしまった場合には、 Option（WindowsはAlt）キーを押しながらドラッグすると、不要な選択範囲を削除することができます。
  • Tシャツから選択範囲がはみ出て、デニムの部分も選択されてしまいました。

3. Option（Windowsの場合はAlt）キーを押しながら、不要なデニム部分の選択範囲を削除します。

4. 「イメージ」メニューの「色調補正」から「色相・彩度」を選びます。

5. 「色相・彩度」のダイアログボックスが表示されますので、色相のスライダのつまみを左右に動かし、好みの色味に変えてから「OK」ボタンで確定します。

6. 「選択範囲」メニューから「選択を解除」を選び、選択範囲を解除します。

7. 完成です。

選択範囲の解除について
  • Photoshopの大半の機能は選択範囲内にしか適用されないため、作成した選択範囲が表示されたままになっていると、別の箇所の画像編集の作業に移行できません。そこで、「選択を解除」という選択範囲の表示を消す操作が必要になります。
  • 「選択範囲」メニューから「選択を解除」とショートカットキーの⌘+D（WindowsはCtrl+D）を覚えておくとよいでしょう。

クイックマスクモード

　
  • クイックマスクモードとは、一時的に選択範囲を半透明のカラーで表示する機能です。
  • ブラシツールを使用して黒と白で描画することにより、選択範囲の形を修正することができます。

作成手順

1. マグネット選択ツールで手前のクロワッサンを選択したところ、選択範囲が被写体からはみ出したり、逆に内側に入り込んだりしてしまいました。
  • この両方をクイックマスクモードを使い修正します。

2. ツールパネルの「クイックマスクモードで編集」ボタンをクリックします。

3. 破線の選択範囲だった箇所が半透明のカラーで表示されます。

4. 「クイックマスクモードで編集」ボタンをダブルクリックすると、「クイックマスクオプション」が表示され、ここで表示色の変更ができます。
  • 画像に合わせて見やすい色を選んで下さい。
  • 今回は半透明の赤で作業します。

5. ツールパネルから「ブラシツール」を選びます。
  • 「クイックマスクオプション」の「選択範囲に色を付ける」が選択されている場合は、黒で塗ると半透明の赤で表示され、選択範囲を追加できます。
  • 白で塗ると半透明の赤が消え、選択範囲が削除されます。

6. クイックマスクモードから元の画像描画モードに戻すと、選択範囲が作成されます。
  • 画像描画モードに戻すには、ツールパネルの「画像描画モードで編集」ボタンをクリックします。

7. 画像描画モードに戻り、選択範囲の修正が完了しました。

選択とマスク

  • 「選択とマスク」は、クイックマスクに似た機能で、 すでに作成されている選択範囲の境界部分を、被写体に合わせて調整する機能です。
  • 髪の毛や動物の毛など、細かく複雑な境界の選択範囲を作成することができます。
    • ここでは、「選択とマスク」を使い、2枚の写真を以下のように合成します。

画像素材：選択とマスク.jpg、楕円形選択ツール.jpg

作成手順

1.木の枝をざっくりとおおまかに選択する。

1. まず、自動選択ツールで背景の夜空を選択します。
  • shiftキーを押しながらクリックしていくと、徐々に選択される領域が追加されていきます。
  • 木の枝との境界部分はざっくりとおおまかに選択されている状態でかまいません。

2. 次に、この選択範囲を反転します。
  • 「選択範囲」メニューから「選択範囲を反転」を選びます。

3. 選択範囲が反転され、木の枝の側が選択範囲になりました。

2.「選択とマスク」で選択範囲の境界線を調整してからコピー&ペーストする。

1. 選択範囲を作成した状態でオプションバーの「選択とマスク」ボタンをクリックすると、「選択とマスク」ワークスペースが表示されます。
  • 「選択とマスク」ボタンは、選択系ツールのオプションバーに表示されますので、自動選択ツール以外のツールで選択範囲を作成しても使用可能です。

2. こちらが「選択とマスク」ワークスペースです。
  • プレビュー画面で、現在の選択範囲の形が確認できます。
    • 枝と枝の隙間部分がまだ選択範囲に含まれていることがわかります。
  • 半透明の赤い部分が「選択範囲外」を表しています。

3. 「属性パネル」の表示モードで、いろいろなプレビューの表示状態を選択できますので、見やすい色を選びましょう。
  • 今回は、クイックマスクモードのように作業できるオーバーレイを選んで作業します。

4. いよいよ選択範囲の境界線を調整します。
  • 「選択とマスク」ワークスペースのツールパネルから「境界線調整ブラシツール」を選びます。

5. ブラシのサイズを大きめに設定し、画面上をドラッグで描画すると、枝の隙間に赤のカラーが入っていきます。

6. 「属性パネル」最下部の「出力先」で「選択範囲」を選んでから「OK」ボタンをクリックします。

7. 選択範囲が作成されました。

8. ⌘+C（WindowsはCtrl+C）で選択範囲内の画像をコピーし、⌘+V（WindowsはCtrl+V）でペーストします。
  • それから背景レイヤーの表示アイコン（目玉アイコン）をクリックして非表示にしておきます。
  • 木の枝の部分だけがレイヤーにコピー&ペーストされていることがよくわかります。

3.グラデーションツールで背景に色をつける。

  • レイヤーパネルで背景レイヤーを選択してから、グラデーションツールで夜空のようなグラデーションを作成して描画します。
  • 背景レイヤーと木の枝レイヤーの間にグラデーションが入ります。
※グラデーションツールの使い方は「6章 塗りつぶしツールとグラデーションツールで描画してみよう​」を参照して下さい。

4.楕円形選択ツールで満月部分を選択してコピーする。

  • ツールパネルから「楕円形選択ツール」を選び、満月部分を選択します。
    • 楕円形選択ツールの使い方は本章「楕円形選択ツール」節を参照して下さい。
  • 選択範囲を作成したら、⌘+C（WindowsはCtrl+C）で選択範囲内の画像をコピーします。

5.木の枝レイヤーの後ろにペーストしてから位置を調整して完成。

  • ⌘+V（WindowsはCtrl+V）で満月をペーストします。
  • 移動ツールで位置を調整して完成です。
※木の枝のレイヤーを移動してしまわないように、レイヤーをロックしておくとよいでしょう。

切り抜きツール

4. 切り抜き（トリミング）が完了しました。
