【2-1】高効率プロンプト設計図（メタプロンプト雛形）の活用

目安の学習時間：45分

なぜ「詳細な日本語」プロンプトを使うのか？

Nano Banana Proのような最新の画像生成AIは、「何を、どこに、どんなスタイルで」描いてほしいかだけでなく、「どんな文字を配置し、どのアスペクト比で作るか」まで具体的に指示することで、その性能を最大限に発揮します。

そこで本講座では、日本語の「要件」を、AIが最も理解しやすい「テキスト・サイズ指定対応の詳細な日本語プロンプト」に自動変換する「高効率メタプロンプト雛形」を配布物として提供します。
メタプロンプト雛形とは？
  • 「メタプロンプト」とは、「プロンプトを作るためのプロンプト」です。
  • この雛形は、「Nano Banana Proが正確に文字を描画するための日本語の指示構造」をテンプレート化したものです。
  • テキスト要素（メイン・サブ・CTA）に加え、サイズ（アスペクト比）も一括で指定できるように設計されています。

配布されるメタプロンプト雛形

本講座で配布する「高効率メタプロンプト雛形」は以下の通りです。

この雛形（ここから## 4.まで）をコピーし、Geminiなどのテキスト生成AIに貼り付けて使用することを推奨します。
## 1. AIへの指示（Role & Task）

- あなたは、世界トップクラスの**シニア・アートディレクター**兼**プロンプトエンジニア**です。
- 以下の【4. 入力欄（User Input）】にある要件を分析し、**Nano Banana Pro**で「プロの商業広告レベルのバナー」を生成するための、「詳細かつ構造化された**日本語**プロンプト」と「強力な**日本語**ネガティブプロンプト」を作成してください。
- ユーザーの入力が簡素であっても、あなたはプロの感性で**「光の演出」「背景の質感」「構図の工夫」**を補完し、記述を膨らませてください。

## 2. 指示ルール（Rules）

### 2-1. PROMPT (日本語)

- 【3-1. OUTPUT FORMAT】に従い、カテゴリ別に出力してください。
- **# デザイン・品質**: 「8K」「アンリアルエンジン5」「商業写真」「広告の傑作」など、クオリティを強制的に上げる単語を含めてください。
- **# 構成・演出 (重要)**: 単調な背景を避けるため、「被写界深度」「シネマティックライティング」「パーティクル（光の粒）」「湯気」「水滴」など、商品の魅力を引き立てる演出キーワードを必ず追加してください。
- **# テキスト**:
    - `Main Text: "テキスト"` (「太字」「立体的な」「装飾的な」などのフォント指示を追加)
    - `Sub Text: "テキスト"`
    - `CTA: "テキスト"` (「光沢のあるボタン」「視認性の高い」などの指示を追加)
- **# サイズ**: `Aspect Ratio: [比率]`

### 2-2. NEGATIVE PROMPT (日本語)

- シンプルな背景や素人っぽさを排除するため、以下の要素を必ず含めてください。
- `低品質, ぼやけた, 素人撮影, フラットなライティング, 単調な背景, 悪い構図, 歪んだ文字, スペルミス, 崩れた人体, 余分な指`

【2-2】プロンプト構造の理解とNano Banana Proの活用

目安の学習時間：30分

プロンプト（雛形）の5要素

メタプロンプト雛形が生成する日本語プロンプトは、Nano Banana Proが最も理解しやすいように、主に5つのカテゴリに分類されています。
カテゴリ
役割と効果
デザイン・品質
画像の「格」を決めます。「8K」「商業広告」などの言葉で、AIに本気を出させます。
主題・スタイル
メインの被写体を描写します。
構成・演出
空気感を作ります。「湯気」「光の粒」「ボケ味」などを加えることで、単調な画像からプロっぽい奥行きのある画像に変化します。
テキスト要素
Main Text, Sub Text, CTAの3要素を定義します。フォントの質感（光沢、立体など）もここで指定されます。
サイズ
画像の比率を指定します。（例：Aspect Ratio: 16:9）

バナーのクオリティを上げるためのネガティブプロンプト

AI任せにすると、照明が当たっていない「フラット」で「単調」な画像になりがちです。
これを防ぐため、NEGATIVE PROMPTには以下の指示が含まれています。
・単調な背景: 背景を一色で塗りつぶすのを防ぎます。
・フラットなライティング: 立体感のないのっぺりした照明を防ぎます。
・素人撮影: 構図やピントが甘い画像を防ぎます。
これにより、AIに対して「プロのカメラマンが撮影したようなライティングと構図」を強制します。

【2-3】AIツールを用いたバナーベースの高速大量出力実践

目安の学習時間：45分

AIツールを用いたバナーベースの高速大量出力実践

このワークフローの最大の強みは「スピード」と「量」です。
Nano Banana Proの設定を活用し、短時間で多くのデザインベースを生成する手順を解説します。
高速大量出力の手順
  1. プロンプトの準備：「メタプロンプト雛形」に要件を入力し、演出入りのプロンプトを生成させます。
  2. Nano Banana Proの起動：Gemini上で「Nano Banana Pro」を呼び出します。
  3. プロンプトの実行：
    • 準備したPROMPTの内容（「デザイン・品質」から「サイズ」まで）を貼り付けます。
    • 続けて、NEGATIVE PROMPTの内容も貼り付け、「画像を生成して」と指示します。
  4. （繰り返し）：結果を見ながら、気に入った演出（例：「湯気をもっと強く」）をチャットで追加指示して、理想に近づけます。

【2-4】2章 -章末課題- [AI生成プロンプトの作成とデザインベースの生成]

目安の学習時間：30分

問題

「地域のハンドメイドマーケット」の告知バナー（横長）の企画を立て、以下の要件を満たすデザインベースを3パターン生成してください。

・要件1: 温かみがあり、親しみやすく楽しげなトーンのデザイン。
・要件2: 画像内に以下の3つのテキスト要素を含めること。
　・メインテキスト：「春のハンドメイド市」
　・サブテキスト：「4/10 開催」
　・CTA：「詳細はこちら」
・要件3: 横長（16:9）のサイズで生成すること。
・要件4: 配布されたメタプロンプトの雛形を用い、要件を「日本語プロンプト」に変換してからNano Banana Proで生成すること。

解答手順

1. 以下の日本語要件を整理します。
　・デザインの種類: Webサイト用告知バナー
　・主題・画像要素: 手作り雑貨（布小物、陶器）、木のテーブル
　・メインテキスト: 「春のハンドメイド市」
　・サブテキスト: 「4/10 開催」
　・CTA: 「詳細はこちら」
　・サイズ: 16:9
　・スタイル・雰囲気: ナチュラル, 温かみがある, 木漏れ日

2. この日本語要件を配布されたメタプロンプトの雛形（の## 4. 入力欄）に適用し、「日本語プロンプト（PROMPT:とNEGATIVE PROMPT:）」を生成します。

3. GeminiのNano Banana Proにプロンプトを入力し、画像を生成します。
4. 生成したデザインベースの中から、最も要件に近いものを3パターン選定します。

制作例

生成したバナーをチェックしよう

  • 指定した3つのテキスト（メイン、サブ、CTA）が読みやすく配置されているか？
  • 全体のトーンが「プロの商業広告」レベルのリッチさを感じさせるか？
Canva編集に適したデザインの選択基準

AIが生成した画像から、Canvaでの編集（フェーズ3）に最適なデザインを選ぶ基準は明確です。
・テキストの可読性：文字が崩れすぎておらず、読めるものを選びます。
・演出の質：光の当たり方や背景の処理が美しく、安っぽくないものを選びます。
・要素のバランス：メインテキスト、サブテキスト、CTAの配置バランスが良いものを選びます。
