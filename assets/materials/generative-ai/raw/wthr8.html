クライアントから「LP文章をAIで作りたいんですが、ChatGPTとClaude、どっちがいいですか？」と聞かれた。「なんとなくClaude使ってます」とは言えるけど、なぜそちらが良いのか、言葉で説明しようとしたら詰まってしまった…

⚡ このレッスンで躓きやすいポイント

「どれも同じじゃないの？」と感じやすいポイントです。違いを実感するには、同じ文章を両方のAIで生成して比べてみるのが一番の近道。まずは「Claudeは長文が得意」という1点だけ覚えるところから始めましょう。

生成AIツールの全体像

まず、主要な生成AIチャットツールを整理します。ChatGPT・Gemini・Claudeの3つはいずれも「チャット型AI」です。テキストで質問すると回答が返ってくる—基本的な使い方は同じです。

では、何が違うのか。以下の比較で確認してみましょう。

ツール 提供元 特に得意なこと デザイナー・フリーランス向け評価
ChatGPT OpenAI 汎用性が高い。プラグイン・画像生成など機能が豊富 ◎ 汎用性
Gemini Google Google Workspace・検索との連携が得意 ◎ Google連携
Claude Anthropic 長文処理・論理的な文章・コード生成が特に強い ◎ 長文・論理
ポイント

「どれが一番いいか」という答えはありません。業務の内容によって使い分けるのが現実的です。この講座では、デザイナー・フリーランスの業務でClaudeが特に活きる場面に絞って学びます。

✏️ 確認クイズ
Q1. クライアントからLPの文章を長文で作ってほしいと依頼された。Claudeが特に向いている理由は？
正解です！Claudeはコンテキストウィンドウ（一度に処理できる情報量）が大きく、長い文章を精度高く処理するのが得意です。LP文章や提案書など、長くて複雑な文章生成に特に向いています。
Claudeが選ばれる理由は料金や画像生成ではなく「長文処理の精度」です。コンテキストウィンドウが大きいため、長い文章を渡しても精度が落ちにくいのが特徴です。

Claudeが得意な3つのこと

デザイナー・フリーランスの業務でClaudeが特に活きる強みを3つ紹介します。

① 長文処理

Claudeは一度に読める情報量（コンテキストウィンドウ）が非常に大きいのが特徴です。A4数十〜数百ページ分のテキストを渡しても処理できます。競合サイトを丸ごと貼り付けてコピー分析させる、PDFを要約させるといった使い方が得意です。

もっと深掘り！ コンテキストウィンドウとは？
AIが「一度に記憶しながら処理できる情報量」のことです。コンテキストウィンドウが小さいと、長い文章を渡すと途中から忘れたり、回答の精度が落ちたりします。Claudeは現時点でこのウィンドウが非常に大きく、長いプロジェクトの資料を丸ごと渡して「これをもとに提案書を書いて」といった指示が通りやすいのが強みです。

② 論理的で自然な日本語

提案書・LPコピー・ブログ記事など、読み手を説得する文章を自然な日本語で生成することが得意です。「です・ます調で、専門用語を使わずに」といった細かい条件指定にも対応します。

③ コード・HTML生成

コードを書かなくてもHTMLやCSSを生成してプレビューできます。「Artifacts」機能を使えば、チャット画面の中でLPの構成案をすぐに確認できます（Chapter 3で詳しく学びます）。

💡 こんな場面で使える！
  • 競合サイトのテキストを貼り付けて「このサイトの訴求ポイントを分析して」
  • ヒアリングシートを渡して「これをもとにLP文章の下書きを作って」
  • 「提案書の構成案を箇条書きで出して、論理的な流れにして」
✏️ 確認クイズ
Q2. デザイナーがクライアントの提案書を作成する際、Claudeを使うメリットとして最も適切なものは？
正解です！ヒアリングシートや資料をClaudeに渡して「これをもとに提案書の文章を書いて」と指示するだけで、論理的な文章の下書きができます。ゼロから文章を考える時間を大幅に減らせます。
ClaudeはFigma連携や画像生成はできませんが、テキスト生成では高い性能を発揮します。特にヒアリング内容を渡すだけで提案書の論理的な文章の下書きを作れるのが強みです。

この講座でのClaudeの位置づけ

Claudeにはいくつかの使い方があります。この講座が対象とするのは「ブラウザ版Claude（claude.ai）」です。

使い方特徴この講座
ブラウザ版 Claude.ai ブラウザで開いてすぐ使える。Projects・Artifacts・カスタム指示が使える ✅ この講座の対象
Claude Code ターミナルで動くエージェント型。ファイル操作・コマンド実行ができる → 別コースで学ぶ
Claude API 自動化・開発向け。Make/Zapierと連携してノーコード自動化もできる → Chapter 6で紹介
