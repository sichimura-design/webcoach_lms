2章 やってみよう！AI活用LP実装ワークフロー

この章の目安学習時間：180分

この章で到達できるゴール：

  • AI（GitHub Copilot）を駆使して、デザインカンプに基づいたLPのHTML/CSS/JavaScriptを効率的に実装できる。
  • AIとの対話を通じて、レスポンシブ対応や簡単なインタラクションを実装できる。

【2-1】Step1：AIと実装の最終準備

目安の学習時間：20分

開発環境とファイルの準備

まずはコーディングを始めるための準備を整えましょう。
  1. 作業フォルダの作成: PCの任意の場所に、lyna-lpのような名前で新しいフォルダを作成します。
  2. ファイルの作成: 作成したフォルダをVSCodeで開き、中にindex.html、style.css、script.jsの3つの空ファイルを作成します。
  3. 画像の配置: 使用する画像が入ったフォルダを、2で作成した空ファイルと同じ階層に配置します。

lyna-lp.zip

AIとスタイルガイドを定義する

以前の教材では、SVGのコード解析などから正確なスタイル情報を抽出しました。
今回はJPG画像しかありませんので、AIの画像認識能力を使って、実装の指針となるスタイルガイド（CSS変数）を作成します。
操作手順
  1. デザインカンプのJPG画像をAIにアップロードします。
  2. 以下のプロンプトを入力し、CSS変数を生成させます。 
    このデザインカンプを分析し、Webサイト実装のベースとなるCSS変数を生成してください。
以下の点を考慮してください：
 - **カラー**:
主要な色（背景色、テキスト色、アクセントカラーなど）を抽出し、
`--color-primary`のような役割ベースで命名してください。
- **フォント**: 
見出しと本文で使われているフォントファミリー（Serif系かSans-serif系か）と、
おおよそのフォントサイズを推測し、`--font-family-heading`や`--font-size-lg`のように命名してください。
生成した変数は:root内で定義し、
それぞれの変数がデザインのどの部分に対応するかのコメントも追加してください。
  3. 生成されたCSS変数コードをコピーし、`style.css`ファイルの先頭に貼り付けます。 
:root {
  /* Color Palette 
    役割ベースで命名したカラー変数です。
  */

  /* 基本の背景色 (ほぼ白) */
  --color-background: #FFFFFF; 
  
  /* 主要なテキストカラー (濃いグレー) */
  --color-text-primary: #333333;

  /* 薄いテキストや罫線の色 (ライトグレー) */
  --color-text-secondary: #AAAAAA;

  /* ボタンやアクセントに使われる色 (ゴールド/イエロー) */
  --color-accent: #E5B842; 

  /* メールマガジンセクションの背景色 (ミディアムグレー) */
  --color-background-secondary: #707070;

  /* フッターなどの背景色 (白) */
  --color-surface: #FFFFFF; 


  /* Typography 
    フォントファミリーとサイズに関する変数です。
  */

  /* 見出し用フォント (セリフ体) */
  --font-family-heading: "Garamond", "Times New Roman", serif;

  /* 本文用フォント (サンセリフ体) */
  --font-family-body: "Helvetica Neue", "Arial", sans-serif;

  /* 特大サイズ (セクションタイトルなど) */
  --font-size-xl: 2.25rem; /* 36px */

  /* 大サイズ (小見出しなど) */
  --font-size-lg: 1.5rem; /* 24px */

  /* 中サイズ (基本の本文) */
  --font-size-md: 1rem; /* 16px */

  /* 小サイズ (商品価格や補足情報) */
  --font-size-sm: 0.875rem; /* 14px */

  /* 極小サイズ (フッターのリンクなど) */
  --font-size-xs: 0.75rem; /* 12px */
}
出力例
この一手間により、後のコーディング作業で色やフォントの値を迷うことなく、一貫性のあるスタイルをスピーディーに適用できるようになります。

【2-2】Step2：AIとHTMLの骨格を組む

目安の学習時間：30分

コメント駆動でHTML構造を生成！

ここからは GitHub Copilot を相棒に、HTMLの骨格を効率的に組み上げていきます。
index.html の <body> タグ内に、デザインカンプのセクション構成をコメントとして書き出していきましょう。
GitHub Copilot がコメントを解釈し、適切なHTML構造を提案してくれます。

index.htmlへの記述例
このようにコメントを記述し、改行するとCopilotがheaderタグやsectionタグを使った構造案を灰色の文字でサジェストしてくれます。
「Tab」キーを押して、その提案を採用しながら、全体の骨格を素早く完成させましょう。

練習問題

問題

【2-3】Step3：AIとCSSでデザインを再現する！

目安の学習時間：60分

Copilot Chatで基本スタイルを当てる

HTMLの骨格ができたら、次はCSSでデザインを再現していきます。VSCodeのCopilot Chat機能を開き、対話形式でスタイリングを進めましょう。

Copilot Chatへの指示例
  • 「style.css を開いて。まずは基本的なページ全体のスタイルを設定します。背景色は -color-background、基本の文字色は -color-text-primary を適用してください。」
  • 「header のスタイルを作成します。中のロゴとナビゲーションを横並びにして、上下中央に配置してください。」
  • 「.button というクラスのスタイルを作成します。背景色は -color-accent、文字色は白、角を少し丸めて、内側に適度な余白（padding）を設定してください。」
このように、日本語で具体的な指示を出すことで、Copilot ChatがCSSコードを生成してくれます。
生成されたコードをstyle.cssに貼り付け、ブラウザで表示を確認しながら作業を進めます。

実務でのヒント：レスポンシブのデザイン指示がない場合
  • 実務の現場では、PC版のデザインのみが提供され、タブレットやスマートフォン版の具体的なデザイン指示がないケースは少なくありません。
  • このような場合、開発者にはPC版のデザイン原則やスタイルを引き継ぎつつ、モバイル環境で最適化されたレイアウトを自身で判断して実装することが期待されます。
  • AIの提案にもあるような、以下のような対応が一般的な「よしなに計らう」範囲と言えるでしょう。
    • カラムレイアウト（横並びの要素）を1列にして縦に並べる。
    • PCでは広すぎる余白を、画面幅に合わせて狭く調整する。
    • フォントサイズや画像の大きさを、可読性を損なわない範囲で調整する。
  • デザイン指示がない中で、ユーザーにとって最善の表示を考える力も、開発者にとって重要なスキルの一つです。

【2-4】Step4：AIとJavaScriptで動きをつける(任意)

目安の学習時間：40分

AIと作る「トップへ戻る」ボタン

LPが長くなると、ユーザーがページの先頭に戻るのが大変になります。
そこで、多くのWebサイトで採用されている「トップへ戻る」ボタンを実装してみましょう。
これもAIに相談すれば簡単です。
JavaScript未学習の方へ

このセクション【2-4】では、JavaScriptを使ってWebサイトに「動き」を追加するインタラクションを実装します。

  • JavaScriptをまだ学習していない、あるいは難しいと感じる場合は、このセクションを一旦スキップしても問題ありません。
  • まずはHTMLとCSSだけでデザインカンプの見た目を完成させることを目指しましょう。
  • JavaScriptの学習が進んだ後で、いつでもこの章に戻って挑戦することができます。
Copilot Chatへの相談例
「Webサイトに『トップへ戻る』ボタンを実装したいです。
普段は隠れていて、ある程度下にスクロールしたら右下にフワッと表示され、クリックするとページ上部にスムーズにスクロールする、という仕様です。
この機能を実現するためのHTML, CSS, JavaScriptのコードをそれぞれ生成してください。」

AIが生成したコードをそれぞれのファイルに追記するだけで、リッチなUIを実装できます。
これにより、Webサイトでよく使われるインタラクションの実装パターンを学びます。
以下の手順で「トップへ戻る」ボタンを実装できます。

1. HTML（</body>直前に追加）

  ↑
</button>

2. CSS（style.cssの末尾に追加）

  opacity: 0;

  opacity: 1;

3. JavaScript（script.jsに追加）

document.addEventListener('DOMContentLoaded', function() {
  // トップへ戻るボタン
  const toTopBtn = document.getElementById('toTopBtn');
  window.addEventListener('scroll', function() {
    if (window.scrollY > 200) {
      toTopBtn.classList.add('show');
    } else {
      toTopBtn.classList.remove('show');
    }
  });
  toTopBtn.addEventListener('click', function() {
    window.scrollTo({ top: 0, behavior: 'smooth' });
  });
});

これで、スクロール時に右下へ「トップへ戻る」ボタンが表示され、クリックでスムーズにページ上部へ戻ります。
