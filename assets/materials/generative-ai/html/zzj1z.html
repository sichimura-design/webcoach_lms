2章 AIによるペルソナ分析を身につけよう

この章の目安学習時間：40分

この章で到達できるゴール：

  • ライティングにおけるペルソナ分析の重要性を再確認できる
  • 提供されるプロンプトテンプレートを使い、AIに高精度なペルソナ分析を実行させることができる
  • 作成したペルソナの悩みやニーズを深く掘り下げ、言語化できる

【2-1】なぜペルソナがライティングの質を左右するのか？

目安の学習時間：10分

「誰に」を決めないと、何も伝わらない

優れた文章を書くための第一歩は、「誰に届けたいのか」を明確にすることです。

例えば、「皆さんにおすすめのカメラです」と言われても、ほとんどの人の心には響きません。しかし、「カメラに詳しくないけど、子どもの運動会を綺麗に撮りたいパパへ」と呼びかけると、ターゲットは「これは自分のことだ」と感じ、話を聞く姿勢になります。

このように、不特定多数の「みんな」ではなく、たった一人の「理想の読者」を具体的に設定すること。それがペルソナ分析です。ペルソナを定めることで、文章のトーン、伝えるべき内容、響く言葉が全て明確になり、文章の質は劇的に向上します。
ペルソナ
  • 商品やサービスの典型的なユーザー像を、具体的な人物として設定したもの。
  • 年齢、職業、ライフスタイル、価値観、悩みなどを詳細に設定することで、ターゲットへの理解を深めることができます。

1章で学んだプロンプト技術の応用

このペルソナ分析は、AIが非常に得意とする分野の一つです。

1章で学んだように、AIに「優秀なマーケティングリサーチャーです」といった役割を与え、分析したいテーマや商品情報を伝えるだけで、AIは膨大なデータから想定されるターゲット像を驚くほど具体的に描き出してくれます。

これまで数時間かかっていたリサーチと分析作業を、AIに丸投げすることで、ライターはより本質的な作業に集中できるのです。

【2-2】テンプレート付！AIペルソナ分析の具体的なステップ

目安の学習時間：20分

【配布】ペルソナ分析プロンプトテンプレート

ここでは、コピー＆ペーストしてすぐに使える、高品質な「ペルソナ分析プロンプトテンプレート」を提供します。
このテンプレートを使えば、誰でも簡単に詳細なペルソナを作成できます。
ペルソナ分析プロンプトテンプレート

あなたは優秀なマーケティングリサーチャーです。
以下のテーマについて、最も典型的で具体的なユーザーペルソナを一人設定してください。

# テーマ
[ここに分析したいテーマや商品名を入力]

# 出力項目
- 基本情報（名前、年齢、性別、職業、年収、家族構成）
- ライフスタイル・価値観
- 情報収集の方法（よく見るWebサイト、SNSなど）
- 抱えている悩み（3つ以上）
- 商品やサービスによって得られる理想の未来（3つ以上）

# 注意事項
- 架空の人物ですが、実在するかのようにリアルな言葉で記述してください。
- 表形式で出力してください。

このテンプレートのポイントは、単にペルソナを作るだけでなく、その人が抱える「悩み」と、それによって得られる「理想の未来（ベネフィット）」までを言語化させる点にあります。

これが、後のライティングで非常に重要な要素となります。

テンプレートを使ったペルソナ作成フロー

先程のテンプレートを使用して、ターゲットペルソナを言語化してみましょう。
作業手順
  1. 上記の「ペルソナ分析プロンプトテンプレート」をコピーする。
  2. ChatGPTなどのAIツールの入力画面に貼り付ける。
  3. テンプレート内の[ここに分析したいテーマや商品名を入力]の部分を、例として「地元で人気のパン屋さんの、Instagram投稿」と書き換える。
  4. プロンプトを送信し、AIにペルソナシートを表形式で生成させる。
  5. 生成されたペルソナに対して、「この人の悩みを、もっと深掘りして教えて」といった追加の質問を投げかけ、対話を通じて情報を深化させる様子を示す。

  • 配布した「ペルソナ分析プロンプトテンプレート」を使い、以下のテーマでペルソナを作成してみましょう。
  • テーマ: 「地元で人気のパン屋さんの、Instagram投稿」
  • AIが出力したペルソナの「名前」「年齢」「職業」を解答してください。

上記のデモ動画で示した手順で、実際にAIにペルソナを作成させてみましょう。
AIによって毎回結果は多少異なりますが、以下のようなペルソナが出力されるはずです。
・ 名前：佐藤 ゆうか
・ 年齢：32歳
・ 職業：近所で働く会社員（事務職）

【2-3】2章 -章末課題- [架空サービスのペルソナを設計しよう]

目安の学習時間:10分

問題

新サービス「月額1,500円で使える、AI搭載の献立自動提案アプリ」のライティング担当者になったと想定して、このサービスのペルソナを設計しましょう。
課題:
AIを使って、このアプリの魅力を伝えるためのブログ記事を書くという想定でペルソナを一人作成してください。
提出物:
以下の項目を含む「ペルソナシート」として出力させ、提出してください。
  • 基本情報（名前、年齢、性別、職業、家族構成）
  • ライフスタイル・価値観
  • 抱えている悩み（3つ以上）
  • このアプリで解決できること（3つ以上）

解答手順

操作手順
  1. 配布した「ペルソナ分析プロンプトテンプレート」を開きます。
  2. テンプレートの`[テーマ]`部分を「月額1,500円で使える、AI搭載の献立自動提案アプリ」に書き換えます。
  3. AIにプロンプトを入力します。
  4. 出力された内容が「ペルソナシート」の項目をすべて満たしているか確認します。不足している場合は、「上記のペルソナについて、抱えている悩みを3つ教えてください」のように追加で質問します。
  5. 完成したペルソナシートを提出します。
あなたは、経験豊富なマーケティングリサーチャーです。
以下に紹介する新サービスの魅力を伝えるブログ記事のターゲット読者として、最も典型的で具体的なユーザーペルソナを一人設定してください。

■ サービス概要
サービス名：月額1,500円で使える、AI搭載の献立自動提案アプリ
主な機能：ユーザーの好みやアレルギー、冷蔵庫の中身、栄養バランスを考慮し、AIが1週間分の献立と買い物リストを自動で作成する。
目的：このサービスの魅力を伝え、利用したいと思ってもらうためのブログ記事を作成する。

■ 出力項目
以下の項目を含む「ペルソナシート」を作成してください。

1.基本情報
・名前
・年齢
・性別
・職業
・家族構成

2.ライフスタイル・価値観
・平日・休日の過ごし方
・趣味や関心興味
・お金の使い方に対する考え方
・食生活や健康に対する考え方

3.抱えている悩み（3つ以上）
食事の準備に関して、日常的に感じている具体的な悩みやストレスを記述してください。

4.このアプリで解決できること（3つ以上）
このアプリを利用することで、上記の悩みがどのように解決され、どのような理想の未来が手に入るかを具体的に記述してくだい。

■ 注意事項
・架空の人物ですが、実在するかのようなリアルな言葉と描写で記述してください。
・各項目が明確に伝わるよう、人柄や日常がイメージできるように描写してください。
・特に「抱えている悩み」は、共感を生むために具体的かつ切実に書いてください。
・全体は表形式で出力してください。
プロンプト例

自己添削しよう用！
  • 完成した課題は、以下のポイントを参照して自分で添削してみましょう。
【ポイント】
  • 問題文に記載された４つの項目について、それぞれ出力されているか確認しましょう。
  • 特にペルソナがこのアプリを使うことで、抱えている悩みを解決できるという結びつきが重要です。
これで「2章 AIによるペルソナ分析を身につけよう」の解説を終わります。
