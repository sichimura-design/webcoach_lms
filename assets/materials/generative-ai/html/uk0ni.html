Claude Design（スライド・プロトタイプ生成）

Research Preview 段階
Claude Design
スライドデッキやインタラクティブなプロトタイプを Claude 上で生成できる機能です。テキストで指示するだけで、プレゼン資料のスライドやWebサービスのプロトタイプが生成されます。
ノーコードデザイナーにとって注目の理由：これまで Artifacts で HTML のたたき台を作っていた用途が、スライドやより高度なプロトタイプにまで広がります。「Figma でイチから作る前に Claude でたたき台を生成 → 方向性確認 → Figma で仕上げ」というフローが現実的になります。

Claudeはどこへ向かっているか

Claude はいまや単一のチャットツールではなく、用途ごとに使い分けられる AIのプラットフォーム へと進化しています。

  • 💻
    claude.ai（ブラウザ版）
    この講座で学んだメインの使い方。日常のAIアシスタントとして活用。
  • ⌨️
    Claude Code（ターミナルツール）
    コーディング・ファイル操作・自動化タスクをターミナルから Claude に依頼。APIが必要。
  • 🔌
    API（プログラムからの呼び出し）
    自作ツール・業務フローへの組み込み。プログラムが書ける人・チームで利用。

この講座で学んだ「Projects・Artifacts・長文コンテキスト・カスタム指示」の4本柱は、どのClaude の使い方でも土台になる考え方です。

Claude Design がデザイナーにとって注目の理由を説明できる
スライドデッキやプロトタイプを言葉で指示するだけで生成できるため、これまでツールでイチから作っていたたたき台作成が Claude 上で完結するようになる。「Claude でたたき台 → 方向性確認 → Figma で仕上げ」というフローが実現できる。
claude.ai / Claude Code / API の3つの使い分けを説明できる
①claude.ai：ブラウザで使うチャット。日常業務のAIアシスタント。②Claude Code：ターミナルから使うコーディングAI。API 契約が必要。③API：プログラムから Claude を呼び出す仕組み。自作ツールや業務自動化に使う。
この講座で学んだ4本柱を言える
①Projects（クライアントごとに育てる）②Artifacts（その場で成果物を生成・修正）③長文コンテキスト（大量情報を一括処理）④カスタム指示（自分専用のデフォルト設定）。これらはClaude Code や API を使う際も基礎知識として役立つ。
