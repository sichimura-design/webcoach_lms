この章の目安学習時間：20分

この章で到達できるゴール：

  • 本教材で学んだCopilotの活用法を整理し、自分のスキルとして認識できる。
  • AI時代のコーディングにおける注意点を理解し、プロとしてAIと付き合うための心構えが身につく。

【5-1】AI時代のプロフェッショナルへ

目安の学習時間：20分

AI時代のコーディング作法と注意点

本教材「AIアシストコーディング実践」、お疲れ様でした。
GitHub Copilotという強力なパートナーと共に、コーディングのあらゆるプロセスを効率化するスキルを習得しました。

最後に、これからのAI時代のプロとして、常に心に留めておくべき作法と注意点を再確認しましょう。

そして、最も重要な注意点は「AIの生成物を鵜呑みにしない」ことです。
AIは時に間違いを犯し、最適なコードを提案しないこともあります。
生成されたコードを理解し、テストし、最終的な品質に責任を持つのは、他の誰でもない、開発者自身です。
AIに依存するのではなく、あくまで主体的に使いこなす姿勢を忘れないでください。

これからCopilotを使いこなすために

Copilotは日々進化しています。
今日学んだテクニックをベースに、さらに使いこなしていくためのヒントをいくつか紹介します。
  • ショートカットキーを覚える：
    インライン補完の候補を切り替える（Alt + ] or ]）、Copilot Chatを開くなど、ショートカットキーを覚えると作業効率がさらに上がります。
  • 最新情報をキャッチアップする：
    GitHubの公式ブログや、技術系ニュースサイトでCopilotの最新機能や活用法を常にチェックする習慣をつけましょう。新しいコマンドや機能が追加されているかもしれません。
コラム：Copilot以外のAIコーディングツール

AIコーディングの世界は、Copilotだけではありません。他にも、

  • Cursor：AIネイティブなエディタで、よりシームレスなAI連携が特徴。
  • Amazon CodeWhisperer：AWSのサービスとの連携に強く、セキュリティスキャン機能も備える。

などのツールが存在します。Copilotで基本をマスターすれば、これらの新しいツールにもすぐに対応できるようになるはずです。常にアンテナを張っておきましょう。
