2章 フィード投稿の効果を倍増させるストーリーズ連携術

この章の目安学習時間：60分

この章で到達できるゴール：

  • フィード投稿の閲覧数を増やすための、効果的なストーリーズ活用法を実践できる
  • インタラクティブスタンプを使い、フォロワーを巻き込みながら投稿を告知できる

【2-1】[投稿前] 期待感を高めるティザー（予告）術

目安の学習時間：30分

なぜティザー（予告）が有効なのか

フィード投稿は、ただ投稿するだけではアルゴリズムの関係上、全てのフォロワーに表示されるわけではありません。
そこで重要になるのが、投稿前にストーリーズで「ティザー（予告）」を行うこと​です。
ティザー（予告）の2大効果
  • 見逃し防止（リマインド効果）：事前に「〇時に投稿します！」と知らせることで、フォロワーがその時間に合わせてアカウントを見に来てくれる可能性が高まります。
  • 初速アップ効果：投稿直後のエンゲージメント（いいね、コメント、保存など）が高いと、Instagramのアルゴリズムが良い投稿と判断し、発見タブなどで拡散されやすくなります。ティザーで期待感を高めておくことで、この「初速」を高めることができます。

実践：カウントダウンスタンプ

ティザーで最も効果的なのが、ストーリーズの「カウントダウン」スタンプです。
「明日20時、新投稿！」といった予告ストーリーズにこのスタンプを追加すると、フォロワーはスタンプをタップして「リマインダー設定」ができます。
設定すると、指定した日時にフォロワーへ通知が届くため、投稿の見逃しを強力に防ぐことができます。

2A-3-2章-1

実践：クイズ・アンケートスタンプ

投稿内容に関連したクイズやアンケートをティザーとして使うのも、フォロワーを巻き込む楽しいテクニックです。
  • クイズの例：レシピ投稿の前に「私が最近ハマっている隠し味、なーんだ？」とクイズを出す。
  • アンケートの例：「次の投稿テーマ、どっちが知りたい？」とアンケートを取り、票が多かった方のテーマで投稿を作成する。
これにより、フォロワーは投稿を「自分ごと」として捉え、公開を楽しみにしてくれるようになります。

練習問題：ティザーストーリーズを作成しよう

問題

明日「簡単節約レシピ」というテーマのフィード投稿をすると仮定して、そのティザー（予告）となるストーリーズを、カウントダウンスタンプを使って作成してください。

解答手順

  1. Canvaなどで「明日20時、新作レシピ投稿！」「【節約術】見なきゃ損する神レシピ」といったテキストを入れた簡単な画像を作成します。
  2. Instagramのストーリーズ作成画面で、作成した画像を背景に設定します。
  3. スタンプアイコンから「カウントダウン」を選択し、名前を「新作レシピ投稿」などに設定します。
  4. 終了日時を明日の20時に設定し、スタンプを配置して投稿します。

【2-2】[投稿後] 見逃しを防ぐシェア術

目安の学習時間：30分

ただシェアするだけではNG

フィード投稿を公開したら、必ずストーリーズにも「シェア（再投稿）」しましょう。
これにより、フィード投稿を見逃してしまったフォロワーにも情報を届けることができます。

ただシェアするだけでなく、GIFスタンプや手書きペンで投稿の一部を隠すのがポイントです。
「隠されている部分が見たい」という心理が働き、フィード投稿へのタップ率が向上します。

投稿内容を深掘りする

シェアする際に、フィード投稿では語りきれなかった裏話や補足情報を添えるのも非常に効果的です。
  • レシピ投稿の例：「実はこの時、塩と砂糖を間違えそうになりました(笑) 皆さんも気をつけて！」
  • ノウハウ投稿の例：「この投稿で一番伝えたかったのは、3枚目の〇〇です！」
このような人間味あふれる補足は、アカウントへの親近感を高め、ファン化を促進します。

【2-3】2章 -章末課題- ペルソナに合わせたストーリーズ連携プランを作成しよう

問題

以下の2つのシナリオから1つを選び、指定されたフィード投稿のリーチを最大化するための「ストーリーズ連携プラン」を企画してください。
プランには、この章で学んだ「投稿前のティザー（予告）」と「投稿後のシェア」の両方を含め、それぞれ最低1つ以上のアクションを具体的に記述してください。

【選択シナリオ】

シナリオA

  • ペルソナ： 都内で働く20代独身女性
  • フィード投稿テーマ： 「週末に行きたい！ご褒美アフタヌーンティー5選」

シナリオB

  • ペルソナ： 小学生の子供を持つ30代のワーキングマザー
  • フィード投稿テーマ： 「フライパン1つで完成！週末の作り置きレシピ5選」

解答手順

  1. シナリオAまたはBを選択します。
  2. 選択したシナリオのペルソナの気持ちになりきり、「どんな予告があれば見たくなるか」「どんなシェアの仕方をすればタップしたくなるか」を考えます。
  3. 「投稿前のティザープラン」と「投稿後のシェアプラン」を、時間を追って具体的に作成します。
  4. 作成したプランを提出します。

解答例

【解答例：シナリオA を選択した場合】

  • ペルソナ： 都内で働く20代独身女性
  • 題材フィード投稿： 「週末に行きたい！ご褒美アフタヌーンティー5選」
  • 【投稿前】ティザープラン
    • アクション①（投稿24時間前）：
      • 目的： 投稿テーマへの興味喚起と、フォロワーの好みのリサーチ。
      • 内容： 「週末のご褒美といえば、どっち派？」というテキストと共に、アンケートスタンプで「①優雅にホテルでアフタヌーンティー」「②隠れ家カフェでまったり」の二択を提示する。
    • アクション②（投稿3時間前）：
      • 目的： 投稿時間の最終告知と、見逃し防止。
      • 内容： アフタヌーンティーのキラキラした写真の一部を見せ、「今夜21時、週末絶対行きたいご褒美スポットを大公開…✨」というテキストを添え、カウントダウンスタンプを設置する。
  • 【投稿後】シェアプラン
    • アクション①（投稿1時間後）：
      • 目的： フィード投稿へのタップ率向上と、見逃したフォロワーへのリーチ。
      • 内容： フィード投稿をストーリーズにシェアし、5つのホテルのうち最も豪華な1枚の写真をGIFスタンプ（例：「TAP!」「キラキラ」など）で隠す。「1つめはどこでしょう？タップしてチェック👆」と誘導する。

【解答例：シナリオB を選択した場合】

  • ペルソナ： 小学生の子供を持つ30代のワーキングマザー
  • 題材フィード投稿： 「フライパン1つで完成！週末の作り置きレシピ5選」
  • 【投稿前】ティザープラン
    • アクション①（投稿24時間前）：
      • 目的： 投稿テーマへの共感醸成と、悩みの自分事化。
      • 内容： 「作り置きに関するお悩み、何でも教えて！」と質問スタンプを設置し、フォロワーのリアルな悩みを募集する。
    • アクション②（投稿3時間前）：
      • 目的： 投稿時間の最終告知と、見逃し防止。
      • 内容： 「そのお悩み、今夜21時の投稿で解決します…🔥」というテキストと共に、カウントダウンスタンプを設置する。
  • 【投稿後】シェアプラン
    • アクション①（投稿1時間後）：
      • 目的： フィード投稿へのタップ率向上と、見逃したフォロワーへのリーチ。
      • 内容： フィード投稿をストーリーズにシェアし、「本当にフライパン1つでできるの…？」というテキストと、フライパンのイラストを手書きペンで描き加え、「詳しい作り方はタップして見る▶」と誘導する。
これで「2章 フィード投稿の効果を倍増させるストーリーズ連携術」の解説を終わります。
