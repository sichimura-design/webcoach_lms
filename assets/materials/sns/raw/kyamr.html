3章：視聴維持率を高める台本作成と動画制作実践

この章の目安学習時間：180分

この章のゴール

この章を終えると、以下の状態になります。

  • 視聴者を惹きつける「台本」が書けるようになる。
  • 台本・撮影・編集の一連の流れを実践し、投稿用の動画が1本完成する。

学習の進め方

この章は以下の手順で進めます。

  • インプット（動画学習）：視聴維持率を高める構成（フック、改変PREP法）を学ぶ。
  • チェック（理解度確認）：構成の型を振り返る。
  • アウトプット（実践ワーク）：台本を書き、実際に撮影・編集を行う。
  • コーチング（提出・改善）：台本または動画を提出し、フィードバックを受ける。

理解度チェック問題
  • Q1. 視聴者が動画を見るか判断する「最初の2秒」を何と呼びますか？
  • Q2. 視聴者を惹きつけるための構成の型の順番を答えてください。（フック → ？ → 本題 → ベネフィット → ？）
  • Q3. あなたのジャンルで「共感」を得るためのキーワードを1つ挙げてください。

リールの本質的な分析とは

トレンドリサーチを行う際、ただ漠然眺めるだけでは、表面的な模倣で終わってしまいます。重要なのは、「なぜそのリールは、ターゲットの心に刺さり、最後まで見られ、アクションにつながったのか？」というヒットの構造そのものを解明することです。

優れたリールは、ターゲットとなるたった一人の人物（N1）が抱える悩みや欲求を深く理解し、それに応える形で設計されています。

ここでは、その「たった一人」が思わず動画に引き込まれてしまうプロセスを3つのステップに分解し、それぞれで分析すべき具体的な観点を解説します。この分析力が、あなたのリールの質を飛躍的に向上させます。

STEP1：なぜ「目」を留めたのか？（冒頭の引力）

無限に動画が流れてくるフィードの中で、指を止めさせるための工夫を分析します。

  • テーマ・切り口：ターゲットが「あ、これ私のことだ」と自分ごと化できるテーマ設定になっているか？どんな悩みや欲求にアプローチしているか？
  • 冒頭の映像・テキスト：最も伝えたい結論や、視聴者の興味を引く衝撃的な映像（パワーワード）が冒頭1秒で提示されているか？（例：「9割が知らない〇〇」「これ、やばすぎ…」）

STEP2：なぜ「見続け」たのか？（離脱させない工夫）

視聴者を飽きさせず、最後まで惹きつけるためのクリエイティブ要素を分析します。

  • 構成・シナリオ：どんなストーリー展開になっているか？（例：問題提起→共感→解決策）視聴者の感情がどう動くように設計されているか？
  • テンポ・編集：カットの速さ、間の取り方は心地よいか？情報を詰め込みすぎていないか？飽きさせないための緩急はついているか？
  • あしらい（デザイン）：テロップのフォント、色、大きさは動画の雰囲気に合っているか？強調したい部分でエフェクトや効果音が効果的に使われているか？
  • 音源・BGM：動画全体の雰囲気をどう演出し、視聴者の感情を盛り上げているか？ナレーションがある場合、声のトーンや話す速さは適切か？

STEP3：なぜ「アクション」したのか？（心を動かす仕掛け）

視聴後、「いいね」や「保存」「コメント」といった行動を促すための仕組みを分析します。

  • 有益性・共感性：「後で見返したい」「これは覚えておこう」と思わせる、価値ある情報が含まれているか？（→保存）「わかる！」「面白い！」といった共感ポイントはどこにあるか？（→いいね・シェア）
  • 行動喚起（CTA）：「〇〇についてコメントで教えて！」「続きはキャプションへ」など、具体的なアクションを促す言葉が動画の最後やキャプションに含まれているか？（→コメント・プロフィール閲覧）
  • アカウントへの期待感：「この人の他の投稿も見てみたい」と思わせる専門性、キャラクター性、世界観が表現されているか？（→フォロー）

これらの視点で人気のリールを分析することで、単なるトレンドの模倣ではなく、あなたのアカウントだからこそ作れる、再現性の高いヒット企画を生み出すことができます。

AIを活用した台本作成のポイント

視聴維持率を高める台本作成には、ChatGPTなどのAIツールが非常に有効です 。これは、情報構成のフレームワークである改変PREP法（フック、共感、本題、ベネフィット、CTA）の要素に基づき、AIに構成案や具体的なセリフを効率良く生成させる手法です 。

AIを使う際は、漠然とした指示ではなく、「誰向け」「目的」「構成の型」を明確に伝えるプロンプトエンジニアリングが鍵となります。また出力された台本をもとにAIと壁打ちをしたり、自分の手で改良することが必要不可欠です。

2. 実践ワークブック（アウトプット）

Mission：投稿用動画を1本完成させる

1章で決めたジャンルで、実際に投稿するための動画を作成します。

▼ ワーク1：競合動画を分析してTTPする
1章で見つけたベンチマークアカウントの動画の中から、特に再生数が高いものを3つ以上選び、その構成を参考にします。
  • 冒頭の言葉は？
  • 展開の順番は？
  • カットの切り替えテンポは？
プロの収益化戦略：主要な手段の理解
  • ショート動画で収益を得る方法は多岐にわたりますが、自社サービス（オリジナルグッズなど）やライブ配信をしない場合、「企業案件」と「アフィリエイト」の二つが、あなたの収益の核となります。
  • この二つの成功は、いかに視聴者を離脱させずに「商品やサービスの購買行動」に結びつけられるかにかかっています。
  • 将来的な企業案件獲得やアフィリエイトの成功に繋げるため、自分のジャンルのみならず、以下のアカウントがどのようにして購買行動を促す台本構成を用いているかを徹底的に分析してみましょう。

▼ ワーク2：撮影・編集指示を統合した台本を完成させる
以下の流れでを使って台本を書いてください。
  1. フック（0-2秒）：視聴者の足を止める強力な一言（結論、疑問、意外性など）。
  2. 共感（2-5秒）：「わかる」「私もそうだった」と思わせる内容。
  3. 本題（5秒〜）：ノウハウや情報の提供。
  4. ベネフィット：それを行うとどうなるか、得られる未来。
  5. CTA（最後）：いいねやフォロー、プロフィールのリンクタップを促す言葉。

3. 課題の提出（コーチング）

作成した動画（MP4ファイル）を、Slackでコーチにメンションをつけて共有してください。
※不安な場合は、撮影前に「台本」の段階で一度共有してフィードバックをもらうことも可能です。
提出前チェックリスト
  • 冒頭2秒で「何の動画か」がわかりますか？
  • 無駄な間（ま）がなく、テンポよく進みますか？
  • 見終わった後、視聴者に「何をしてほしいか」が伝わりますか？
理解度チェック解答例
  • 解答1：フックと呼びます。
  • 解答2：フック → 共感 → 本題 → ベネフィット → 行動（CTA） です。
  • 解答3：「あるある」や「私だけじゃなかった」と感じさせるような、ターゲットの悩みや日常を表すキーワード。（例：一人暮らし、ズボラ、仕事で疲れた、初心者）
