【4-1】4章 -章末課題- 構成に沿ってリールを完成させよう

これまで学んだ全てのスキル（撮影、カット編集、テロップ、BGM、効果音、キーフレームなど）を使って、テーマに沿ったリールを制作してください。

問題

制作サイズ・秒数・構成に指定を確認してターゲットに沿った見やすく分かりやすい投稿を制作してください。

ジャンル タイトル 制作サイズ 秒数 ターゲット 構成詳細
WEB メールの書き出し5選 1080×1920px 〜20秒 20〜30代・女性 構成文はこちら
WEB ショートカット登録術 1080×1920px 〜40秒 20〜30代・女性 構成文はこちら

解答手順

  1. 【撮影】：構成文を元に必要な動画素材や写真素材を撮影・準備します。
  2. 【編集】：CapCutを使い、これまでの章で学んだスキルを総動員して動画を編集します。
    • テンポの良いカット編集
    • 読みやすく、デザインされたテロップとアニメーション
    • イメージに合ったBGMと、動きを強調する効果音
    • キーフレームを使った、作品を魅力的に見せる動きのある演出
  3. 【レビュー】：完成した動画を客観的に見直し、「伝えたい情報がターゲットに分かりやすく伝わるか？」「見ていて飽きないか？」という視点で改善点がないかチェックします。
  4. 完成したリール動画を書き出して、提出します。
