13章 ポートフォリオ制作と案件獲得準備

この章のゴール

この章を終えると、以下の状態になります。
  • 様々なジャンルの動画に対応できる「制作の幅」を身につける。
  • 営業活動に使える、魅力的な「ポートフォリオサイト（実績集）」が完成する。
  • 案件獲得に向けて動き出せる状態になる。

学習の進め方

この章は以下の手順で進めます。期間は2週間〜1ヶ月を想定しています。

  • インプット（動画学習）：ポートフォリオの作り方と、案件獲得の営業フローを学ぶ。
  • チェック（理解度確認）：営業の鉄則を振り返る。
  • アウトプット（実践ワーク）：5つのテーマで動画を作り、ポートフォリオサイトにまとめる。
  • コーチング（提出・改善）：ポートフォリオ全体の添削を受ける。

理解度チェック問題

2. 実践ワークブック（アウトプット）

Mission 1：対応幅を広げる5つの動画制作

ポートフォリオを充実させるため、以下の5つのテーマでサンプル動画（15秒〜30秒程度）を作成してください。
架空の商品やサービスで構いません。
  1. Vlog / 日常系
    • 雰囲気、世界観重視。BGMと映像の調和。
  2. How-to / 教育系
    • 手順解説、スライド形式。わかりやすさ重視。
  3. エンタメ / バラエティ系
    • ツッコミ、早いテンポ、面白いエフェクト。視聴維持重視。
  4. ビジネス / インタビュー系
    • 社長インタビュー、対談。信頼感、声の聞き取りやすさ重視。
  5. 商品紹介（Product）系
    • 物撮り、シズル感。購買意欲の喚起（セールスライティング）。

どんな動画を作成しようか思いつかない人は以下のテーマを参考につくってみましょう。

エンタメ / バラエティ系📚 「あるある」学生時代の授業

Mission 2：ポートフォリオサイトの作成

作成した動画をまとめ、営業用のページを作ります。
Notion、foriio、Wix、またはPDFなど、見やすい形式で作成してください。

▼ 掲載必須項目
項目
記載すべき内容
① クリエイター概要
活動名、経歴、強み、ビジネス用連絡先（メールアドレス）。
② アカウント影響力データ
フォロワー数、直近の平均リーチ数、視聴者の属性（年齢、性別、興味関心）。
③ 制作実績（ポートフォリオ）
作成した動画のリンク。
④ 実績データの明記
各動画のリンクに対し、「平均視聴維持率」「保存数」「エンゲージメント率」の具体的な数値。
⑤ 対応可能業務
企画、撮影、編集（テロップ/ナレーション）、サムネイル作成、レポート提出の可否。
⑥ サービスメニューと価格
基本料金（または目安）。単価交渉の考え方、オプション料金。
⑦ コンプライアンス宣言
PR表記（ステマ規制）の遵守、著作権フリー素材の使用を明記。

理解度チェック解答例
  • 解答1：推奨されている5つの動画パターンは、Vlog / 日常系、How-to / 教育系、エンタメ / バラエティ系、ビジネス / インタビュー系、商品紹介（Product）系です。
  • 解答2：ポートフォリオの制作実績に必ず明記すべき客観的なデータ指標は、平均視聴維持率、保存数、エンゲージメント率など、影響力を証明できる具体的な数値です。
