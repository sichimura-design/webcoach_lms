5章 総仕上げ！ゼロからリールを作成してみよう

この章の目安学習時間：20時間

この章で到達できるゴール：

  • これまで学んだ撮影・編集スキルと構成の技術を総動員して、ゼロからプロ品質のリールを制作できる
  • 自分のスキルをアピールするための、ポートフォリオ作品を1つ完成させられる

【5-1】5章 -章末課題-　リールの構成からすべてを自分で作ってみよう

問題

ターゲットや投稿の目的に沿って、投稿に記載するテキストや表紙タイトル・構成を考え、デザインも合わせて制作してください。

こちらは制作サイズ・秒数・表紙タイトル・構成に指定はありません。

ジャンル 内容 ターゲット 投稿の目的
WEB 資料作成のコツ・ポイント紹介 20−30代・女性 見やすく伝わりやすいパワポ資料を作るためのコツ・
意識するポイントを紹介
WEB 業務で使える裏技紹介 20−30代・女性 WordやExcelで使える、知っていると便利な裏技・
豆知識の紹介

解答手順

  1. 【企画】：上記の表を参考に、リールの構成案を考えます。どんな映像とテロップを、どんな順番で見せるかを設計します。
  2. 【撮影】：構成文を元に必要な動画素材や写真素材を撮影・準備します。
  3. 【編集】：CapCutを使い、これまでの章で学んだスキルを総動員して動画を編集します。
    • テンポの良いカット編集
    • 読みやすく、デザインされたテロップとアニメーション
    • イメージに合ったBGMと、動きを強調する効果音
    • キーフレームを使った、作品を魅力的に見せる動きのある演出
  4. 【レビュー】：完成した動画を客観的に見直し、「伝えたい情報がターゲットに分かりやすく伝わるか？」「見ていて飽きないか？」という視点で改善点がないかチェックします。
  5. 完成したリール動画を書き出して、提出します。

解答例

お手本（解答例）をご紹介します。 あくまで一例なので、必ずしもこれだけが正解というわけではありません。

実際に制作したものと比較し、違いを確認してみましょう。

注意
  • 制作前に見るとイメージが引っ張られてしまうため、必ず完成後に確認してください。
ジャンル タイトル 制作例
WEB 資料作成のコツ・ポイント紹介 制作例はこちら
WEB 業務で使える裏技紹介 制作例はこちら
制作物をコーチに添削してもらおう
  • この卒業制作は、これまでの学習成果の集大成であり、あなたのスキルを証明する最初の「動画ポートフォリオ」です。
  • 完成した作品は、必ずコーチに提出し、プロの視点から詳細なフィードバックをもらいましょう。
  • 客観的なレビューを受けることで、自分の強みと、今後さらに伸ばすべき点が明確になり、自信を持って案件獲得に臨むことができます。
