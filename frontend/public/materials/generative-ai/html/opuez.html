2章 AIで投稿文を最適化する！響くテキストコンテンツ作成術

この章の目安学習時間：1時間50分

この章で到達できるゴール

  • ターゲットとSNSの特性に合わせた最適なプロンプトを作成し、投稿文を生成できるようになる
  • ユーザーの目を引くキャッチーな見出しや冒頭文を、AIを使って複数パターン作成できるようになる
  • 保存や購入などの行動を促す効果的なCTA（Call To Action）をAIに提案させ、投稿に組み込めるようになる

【2-1】AIへの指示出しの基礎：ペルソナ×プラットフォーム

目安の学習時間：30分

良い投稿文は「誰に」「どこで」伝えるかが鍵

AIに効果的なSNS投稿文を生成させるためには、まず「誰に」（ターゲットオーディエンス）、「どこで」（プラットフォーム）伝えるのかを明確に指示することが不可欠です。
ペルソナ設定の重要性：
ペルソナとは、サービスや商品の典型的なユーザー像を、具体的な人物像として詳細に設定したものです。AIにこのペルソナ情報をインプットすることで、AIはその人物になりきったり、その人物に響くような言葉遣いや内容を生成しやすくなります。
重要語句：ペルソナ
  • サービスや商品の典型的なユーザー像のこと。
  • 年齢、性別、職業、価値観、ライフスタイル、抱えている悩み、興味関心などを具体的に設定します。
  • AIにペルソナを伝えることで、よりターゲットに最適化されたアウトプットが期待できます。
プラットフォーム特性の考慮：
各SNSプラットフォームには、それぞれ独自の文化やユーザー層、最適な投稿形式があります。例えば、Instagramはビジュアル重視で若年層に人気があり、X（旧Twitter）はリアルタイム性と情報拡散力に優れ、ビジネス層の利用も多い、TikTokはショート動画が中心でエンタメ性が高い、といった特徴があります。これらの特性をAIに伝えることで、プラットフォームに最適化された投稿文を生成できます。

そして、AIに特定の役割を与えることも有効です。例えば、ChatGPTに「あなたはプロのSNSマーケターです」と役割を指定することで、その役割になりきって専門的な視点からアドバイスや文章を生成してくれるようになります。これは、AIの能力を引き出すための「魔法の言葉」の一つと言えるでしょう。

実践：ペルソナとプラットフォームをAIにインプットするプロンプト

実際にペルソナとプラットフォーム情報をAIにインプットする際のプロンプト例を見てみましょう。
以下は、ペルソナ設定の際に考慮すべき項目をまとめたテンプレートです。AIに指示を出す際は、これらの情報を盛り込むと良いでしょう。
  • ペルソナ設定テンプレート（AIへの指示用）
    • 基本情報
      • 年齢層：（例：20代後半、30代、40-50代）
      • 性別：（例：女性、男性、問わない）
      • 居住地：（例：都市部、地方都市、〇〇県）
      • 職業：（例：会社員（デスクワーク中心）、主婦、学生、フリーランス）
      • 家族構成：（例：独身、既婚（子なし）、既婚（小学生の子どもあり））
    • ライフスタイル・価値観
      • 興味関心：（例：美容、健康、旅行、料理、自己投資、特定の趣味）
      • 悩み・課題：（例：時間がない、運動不足、ストレス、キャリアアップ、子育ての悩み）
      • 情報収集の方法：（例：SNS（特にInstagram）、Webメディア、友人知人からの口コミ）
      • SNS利用動向：（例：毎日利用、情報収集がメイン、暇つぶし、特定のインフルエンサーをフォロー）
      • 購買行動の特徴：（例：口コミを重視する、コスパを重視する、ブランド志向、衝動買いしやすい）
    • 商品・サービスとの関連
      • 現在の認知度：（例：まだ知らない、名前だけ聞いたことがある、興味を持っている）
      • 利用経験：（例：なし、過去に一度利用、リピーター）
      • 期待すること：（例：悩みを解決してほしい、新しい体験をしたい、お得に利用したい）

【2-2】読者の心を掴む！キャッチーな見出し・冒頭文のAI生成

目安の学習時間：30分

最初の2秒が勝負：見出しの重要性

SNSのフィードは情報で溢れています。ユーザーは一瞬で投稿を読むか読まないかを判断しており、その判断に最も大きな影響を与えるのが「見出し」や「冒頭文」です。最初の数秒、あるいは数文字でユーザーの興味を引けなければ、どんなに素晴らしい内容の投稿も読んでもらえません。

魅力的な見出し・冒頭文には、以下のような役割があります。
  • 注意を引く（アテンション）：数多くの投稿の中から、自分の投稿に目を留めてもらう。
  • 興味を喚起する（インタレスト）：続きを読むメリットや価値を感じさせる。
  • 内容を要約する（サマリー）：投稿全体で何を伝えたいのかを簡潔に示す。
興味を引く見出しには、いくつかの「型」があります。これらを意識することで、AIにも効果的な見出しを生成させやすくなります。
  • 読者の心を掴む！見出しの型 代表例
    1. 数字・データ活用型
      • 説明：具体的な数字やデータを入れることで、信頼性や具体性を高める。
      • 例：「たった5分で効果あり！」「顧客満足度98%の秘密」「3つの簡単ステップ」
    2. 問いかけ型
      • 説明：読者に直接問いかけることで、自分事として捉えやすくし、興味を引き出す。
      • 例：「〇〇で悩んでいませんか？」「知らなきゃ損する〇〇とは？」
    3. 意外性・逆説型
      • 説明：常識とは逆のことや、意外な組み合わせを提示して注目を集める。
      • 例：「頑張らない方がうまくいく？」「実は〇〇は体に悪い！」
    4. ベネフィット提示型
      • 説明：読者が得られる具体的なメリットや解決できる問題を明確に示す。
      • 例：「〇〇するだけで美肌に！」「これであなたも〇〇マスター」
    5. 緊急性・限定性アピール型
      • 説明：「今だけ」「限定」といった言葉で、すぐに行動しないと損をする感覚を与える。
      • 例：「本日終了！」「先着10名様限定キャンペーン」
    6. 権威性・実績利用型
      • 説明：専門家や実績のある人・機関の言葉を引用したり、実績を示したりして信頼感を出す。
      • 例：「プロが教える〇〇術」「販売実績No.1の秘密」
    7. ターゲット特化型
      • 説明：「〇〇なあなたへ」のように、特定のターゲットに呼びかけることで当事者意識を高める。
      • 例：「子育てママ必見！」「〇〇業界の新人さんへ」

実践：見出し・冒頭文をAIで量産するプロンプト

AIは見出しや冒頭文のアイデアを大量に生成するのが得意です。上記のような「型」を指定してAIにアイデアを出させることも有効です。
プロンプト例（特定の型を指定して見出しを生成）：

# あなたへのお願い

あなたはキャッチコピーの達人です。

以下のテーマとペルソナに基づき、Instagram投稿用のキャッチーな見出しを5つ提案してください。


# テーマ

「睡眠の質を上げるための3つの簡単な習慣」


# ペルソナ

- 30代女性、会社員、最近寝ても疲れが取れないと感じている


# 見出しの型（以下の型を意識して作成してください）

1. 数字活用型

2. 問いかけ型

3. ベネフィット提示型

4. ターゲット特化型

5. 意外性・逆説型


# 出力形式

- 見出し案を番号付きリストで5つ
もし生成された案がしっくりこない場合や、もっと多くのバリエーションが見たい場合は、「もっとパターンをください」「別の切り口で5つ提案してください」のように追加で指示を出すことで、AIはさらに多くのアイデアを生成してくれます。これを「アイデアを無限に広げるテクニック」と呼びましょう。

生成された複数の案から最適なものを選ぶ基準としては、以下のような点が挙げられます。
  • ターゲットに響くか：ペルソナが興味を持ちそうか、自分事として捉えられそうか。
  • 具体性があるか：曖昧な表現ではなく、何についての投稿か想像しやすいか。
  • 独自性・新規性があるか：ありきたりな表現ではなく、目を引くか。
  • 投稿内容と一致しているか：見出しで煽りすぎて、内容が伴わない「釣り」になっていないか。

【2-3】ユーザーを動かす！CTA（行動喚起）の最適化

目安の学習時間：30分

「いいね」で終わらせないCTAの魔法

素晴らしい投稿文でユーザーの共感や興味を引くことができても、それだけでは十分ではありません。投稿の最後に、ユーザーに「次にとってほしい行動」を具体的に示す「CTA（Call To Action：行動喚起）」を設置することが、エンゲージメントや最終的な成果（例：商品購入、問い合わせ）に繋げるために非常に重要です。
重要語句：CTA（Call To Action）
  • ウェブサイトの訪問者や広告の読者、SNS投稿の閲覧者などに対して、具体的な行動を促すためのメッセージや指示のこと。
  • 日本語では「行動喚起」と訳されます。
  • 例：「詳しくはこちら」「無料サンプルを申し込む」「友だちにシェアしてね」「コメントで教えて！」など。
CTAの目的は様々です。
  • コメントやDMでのコミュニケーション促進（例：「あなたの意見も聞かせてね！」）
  • 投稿の保存を促す（例：「後で見返せるように保存してね！」）
  • プロフィールページへの誘導（例：「他の投稿もチェック！▶ @アカウント名」）
  • ウェブサイトや商品ページへのアクセス促進（例：「詳しくはプロフィールのリンクから！」）
  • 商品の購入やサービスの申し込み（例：「今すぐ購入する」「無料相談はこちら」）
  • イベントへの参加（例：「参加希望者はDMください！」）
なぜCTAがエンゲージメントと成果に直結するのでしょうか？
それは、ユーザーが投稿を読んで「良いな」と思っても、次に何をすれば良いか分からなければ、そのまま離脱してしまう可能性が高いからです。
明確なCTAがあることで、ユーザーは迷うことなく次のステップに進むことができ、結果としてアカウントへの関与が深まったり、ビジネス上の目標達成に繋がったりするのです。

実践：目的に合わせたCTAをAIに提案させるプロンプト

AIにCTAを提案させる際は、まず「投稿のゴール」を明確に伝えることが重要です。例えば、「プロフィールへのアクセスを増やしたい」「コメントでユーザーと交流したい」「商品の購入ページへ誘導したい」など、具体的な目的を指示します。

また、ユーザーが行動しやすいように、心理的ハードルの低いCTAから試すのも有効です。いきなり「購入してください」と促すよりも、「まずは詳細を見てみませんか？」や「気軽にコメントで質問してください」といったCTAの方が、ユーザーは応じやすい傾向があります。
プロンプト例（投稿のゴールを指定してCTAを生成）：

# あなたへのお願い

あなたは行動心理学に詳しいSNSコンサルタントです。

以下の投稿内容とゴールに基づき、読者が思わず行動したくなるようなCTA（Call To Action）の文案を3パターン提案してください。


# 投稿内容の概要

「自宅でできる簡単ストレッチ5選」を紹介するInstagramリール動画のキャプション。

ターゲットは運動不足を感じている20～40代の男女。


# 投稿のゴール

1. まずは「保存」してもらい、後で見返して実践してほしい。

2. 動画で紹介しきれなかった他のストレッチ方法を紹介しているプロフィールにも誘導したい。

3. コメントで気軽に質問や感想を書いてもらい、交流を深めたい。


# トーン＆マナー

フレンドリーで、励ますような優しい口調


# 出力形式

- 上記3つのゴールそれぞれに対応するCTA文案を提案してください。

- 各CTA文案には、使用すると効果的な絵文字も添えてください。

AIが生成したCTAは、そのまま使うだけでなく、投稿文全体の流れに合わせて自然に組み込むことが大切です。例えば、投稿の最後に唐突にCTAを入れるのではなく、本文の内容から自然に繋がるように配置したり、問いかけの形にしたりする工夫が効果的です。
考えてみよう！
あなたが最近見たSNS投稿で、思わずクリックしたりコメントしたりしてしまったCTAはありますか？それはどのような言葉遣いや工夫がされていましたか？
解答例：
  • 「この投稿が役に立ったら、ぜひ『🙌』の絵文字で教えてください！」というCTAを見て、内容が良かったので思わずコメントで絵文字を送った。簡単なアクションだったので参加しやすかった。
  • 「他にも〇〇の裏技をたくさん紹介してるよ！見逃さないようにフォローしてね😉 👉 @アカウント名」というCTAで、他の投稿も気になりプロフィールに飛んでフォローした。具体的なメリットと次のアクションが明確だった。

【2-4】2章 -章末課題- [AIライティング総合演習]

目安の学習時間:20分

問題

あなたは「手作りペットフード」を販売するECサイトのSNS担当者です。
この章で学んだことを総動員し、以下の条件でInstagramのフィード投稿用のテキスト一式を作成してください。ChatGPTなどのテキスト生成AIを必ず使用してください。
  • 商材：国産・無添加のドッグフード「ワンだふるごはん」
  • ターゲット（ペルソナ）：
    • 20代〜40代の女性
    • 犬を家族同然に愛している
    • 愛犬の健康や食事に強い関心がある（例：アレルギー対応、添加物不使用、栄養バランスなどを気にしている）
    • SNS（特にInstagram）で犬関連の情報収集（他の飼い主の投稿、専門家のアドバイス、商品レビューなど）をよく行う
    • 愛犬のためなら多少高くても良いものを与えたいと考えている
  • 投稿の目的：
    • 新商品「ワンだふるごはん お試しセット（初回限定価格）」の認知拡大
    • ECサイトへの誘導（購入促進）
  • 作成するもの：
    1. 投稿の見出し（キャッチコピー）：ユーザーの目を引き、続きを読む気を起こさせるもの
    2. 投稿の本文：商品の魅力（特に国産・無添加、愛犬の健康へのメリット）を伝え、ペルソナの共感を呼ぶもの
    3. 行動を促すCTA：ECサイトへの誘導を意識しつつ、自然な形で次のアクションを促すもの
    4. 関連するハッシュタグ（10個程度）：投稿のリーチを広げるためのもの

解答手順

作成手順
  1. まず、AI（ChatGPTなど）に対して、「あなたはペットフード専門のSNSマーケターであり、犬を深く愛するコピーライターです」といった具体的な役割と、上記のペルソナ情報を詳細にインプットします。
  2. 次に、「国産・無添加のドッグフード『ワンだふるごはん』の新商品『お試しセット』を紹介し、ECサイトへの購入を促すInstagramのフィード投稿文を作成してください」と依頼します。投稿の目的も明確に伝えます。
  3. 見出し（キャッチコピー）については、「愛犬の健康を真剣に考える飼い主さんの心に響くような、魅力的なキャッチコピーを5案提案してください。特に『安心安全な食事を与えたい』というニーズに応えるような言葉を入れてください」のように、複数のパターンを生成させ、その中から最も投稿内容とペルソナに合致するものを選びます。
  4. 投稿の本文については、「商品のこだわり（国産原料、無添加製法）と、それによって愛犬がどのように喜び、健康になるのかを、飼い主さんの気持ちに寄り添いながら感情豊かに伝えてください。例えば、食いつきが良くなる様子や、毛並みがツヤツヤになるイメージなど、具体的なベネフィットを想像させるように記述してください」といった指示を加えます。
  5. CTAについては、「ECサイトの『お試しセット』購入ページ（プロフィール欄のリンクに設置予定）にスムーズに誘導するような、自然でかつ魅力的な行動喚起の文章を作成してください。『初回限定価格』であることのお得感もさりげなく伝えてください」と依頼します。
  6. 最後に、「この投稿内容とターゲット層（犬好き、健康志向の飼い主）に関連性の高い人気のハッシュタグを10個提案してください。一般的なものと、少しニッチなものをバランス良く含めてください」と依頼します。
  7. AIが生成した各パーツ（見出し、本文、CTA、ハッシュタグ）を組み合わせ、全体の流れが自然になるように自分で最終的な編集・調整を行います。特に、ブランドのトーン＆マナーに合っているか、ペルソナに語りかける口調になっているかを確認します。
