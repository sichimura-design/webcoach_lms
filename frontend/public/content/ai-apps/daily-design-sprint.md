## 1. どんなアプリか

### アプリの概要

「デイリーデザインスプリントチャレンジャー」は、受講生がデザインスキルを日々向上させるためのAI搭載学習サポートツールです。対話形式でその日の学習条件（制作時間、分野など）を設定すると、AIがパーソナライズされたデザイン課題を自動生成します。受講生は提示された課題に取り組み、完成したデザインを提出することで、AIから具体的なフィードバックを受け取ることができます。

## 2. 主な機能

### 対話形式での課題設定

アプリを起動すると、AIとの対話が始まります。制作に使える時間、挑戦したいデザイン分野（LP、バナー、SNS投稿など）、参考にしたいデザインテーマ（業界別やテイスト別など、任意）、といった項目を順番に選択していきます。

### パーソナライズされた課題生成

受講生が対話で入力した情報に基づき、AIがその受講生に最適化されたデザイン課題を生成します。課題には、具体的な制作物の内容、サイズ指定、必須要素、推奨カラーパレット、参考レイアウトといったデザイン要件に加え、その課題で特に意識すべき「技術的フォーカス」や「スキルアップポイント」も含まれます。また、設定された制作時間に応じた効率的な「制作プロセス」（アイデア出し、ラフ作成、仕上げの時間の目安）も提案されます。

### デザインへのフィードバック

受講生が制作したデザインをアプリにアップロードすると、AIがそれを分析し、詳細なフィードバックを提供します。フィードバックは、「技術面の評価」（デザイン原則の適用度、ツールの習熟度など）と「クリエイティブ面の評価」（独創性、視覚的効果、メッセージ性など）の両面から行われます。良かった点だけでなく、具体的な改善点やアドバイス、次回挑戦すべきポイントなども提示され、次の学習へと繋げます。

## 3. 操作手順

### Step 1: チャレンジ開始と条件設定

アプリを起動し、AIの問いかけに答える形で、その日のデザインチャレンジの条件を設定します。

対話例:

```yaml
AI: デイリーデザインスプリントチャレンジャーへようこそ！
今日のデザインチャレンジの設定をしていきましょう。
まず、今日使える時間はどのくらいですか？

1. 2時間（上級者向け）
2. 3時間（スピードを意識したい人向け）
3. 5時間（初心者～中級者）

User: 3時間（スピードを意識したい人向け）

AI: 3時間（スピードを意識したい人向け）ですね。
それでは、どの業種のデザインに取り組みたいか教えてください。
取り組みたい業種が思いつかない場合はおすすめを提案します。

例：美容・エステ、飲食店、フィットネス、教育・学習、アパレル、
    食品・飲料、法人向けサービス、コンサルティング、人材サービスなど

User: 美容・エステ

AI: 美容・エステですね。
では、今日チャレンジしたいデザインテイストを選んでください！

1. 高級感と洗練さを感じさせるデザイン
2. 自然やナチュラルさを重視したデザイン
3. 柔らかく女性らしさを表現するデザイン
4. 伝統的でエレガントなデザイン
5. 最新の流行を取り入れたデザイン

他にチャレンジしたいデザインテイストがある場合や、
おすすめを提案してほしい場合はお申し付けください。

User: ラグジュアリー
```

### Step 2: 課題の確認

設定した条件に基づき、AIが具体的なデザイン課題を提示します。内容をしっかり確認しましょう。

対話例:

```yaml
# 【今日のデザインチャレンジ】美容・エステ バナー広告制作 (ラグジュアリーテイスト)

## 制作概要

-   制作カテゴリー: 美容・エステ
-   デザインテイスト: ラグジュアリー
-   目標制作時間: 3時間（スピード重視）

## 課題詳細

### 1. デザイン要件

-   サイズ指定: 1080px × 1920px (縦長/ストーリー形式)
-   主な用途:
    -   Instagram/Facebook Stories
    -   TikTok
    -   YouTubeショート
-   特徴: モバイルデバイス画面全体に表示される縦型コンテンツ
-   適している場面: 新商品告知、特別キャンペーンなど短期間での訴求
-   必須要素:
    -   メインコピー: 極上の癒しをあなたに
    -   サブコピー: 体験するたび美しく
    -   キャンペーン情報: 初回限定75％OFF
    -   CTA (Call to Action): 詳細はこちら
-   使用カラー (参考例):
    -   ゴールド: 高級感、華やかさ
    -   エメラルドグリーン: 落ち着き、高尚さ
    -   朝露のような淡いホワイト: クリーン、純粋さ
    ※ 色の選択は自由です。好みに合わせて調整してください。
-   レイアウト (参考例):
    -   トップ: 目を引くメインコピー
    -   中央: ビジュアルを背景に大きく配置。前景にキャンペーン情報とサブコピー
    -   フッター: CTAをシンプルに配置
    -   アクセント: ゴールドやエメラルドグリーンを使用
    ※ レイアウトも自由に変更可能です。

### 2. 技術的フォーカス

-   特に意識する技術:
    -   レイヤーマスクを使った洗練されたビジュアル合成
-   習得すべきテクニック:
    -   光沢感や金属感の表現
    -   グラデーションを活用した高級感のある背景作り
-   重要なデザイン原則:
    -   ホワイトスペースを活かし、読みやすさと高級感の両立

### 3. スキルアップポイント

-   レイアウトのコツ:
    -   ユーザーの視線が自然に流れるような視覚的動線作り
-   配色テクニック:
    -   高コントラストの使用で視覚効果を強調
-   タイポグラフィの扱い方:
    -   筋の通った統一感あるフォントサイズとウェイトの選択

## 制作プロセス (目標合計: 3時間)

1.  アイデアスケッチ: (15% = 約27分)
2.  ラフ作成: (25% = 約45分)
3.  ブラッシュアップ: (60% = 約108分)

## 提出について

-   完成したら、デザインデータをアップロードしてください。

## 注意事項 (画像アップロード要件)

-   必須要件:
    -   ファイルサイズ: 5MB以下
    -   解像度: 2000 × 2000ピクセル以下
-   推奨条件 (最適なフィードバックのため):
    -   長辺: 1568ピクセル以下
    -   解像度: 1000 × 1000ピクセル以上
```

### Step 3: デザイン制作

提示された課題内容と時間配分を目安に、各自のデザインツール（Figma, Photoshopなど）で制作を進めます。

### Step 4: 提出

デザインが完成したら、アプリの指示に従って制作データをアップロードします。

対話例:

```yaml
User: はい、完成しました！（デザインデータをアップロード）
```

### Step 5: フィードバック確認

アップロード後、AIがデザインを評価し、フィードバックを返します。内容を確認し、次の制作に活かしましょう。

対話例:

```yaml
AI: 素晴らしいデザインですね！具体的なフィードバックをさせていただきます。

【技術面の評価】
▼優れている点
- メインコピーとサブコピーの大きさの対比が効果的
- 文字間隔の調整が適切で可読性が高い
- フォントの組み合わせが統一感がある

▼改善できる点
- CTAボタンのテキストがメインコピーと比べてやや小さい
- サブコピーの行間をもう少し広げるとさらに読みやすくなる

【具体的なアドバイス】
1. タイポグラフィの階層構造
   現在：メイン：48px / サブ：24px / CTA：16px
   提案：メイン：48px / サブ：28px / CTA：20px

2. 文字間隔
   - メインコピー：現在の150%に広げる
   - サブコピー：行間を1.5から1.8に調整

次回のチャレンジに向けて、以下の点にも挑戦してみましょう：
- フォントウェイトの違いを活用した強弱表現
- テキストのアライメントバリエーション
- 装飾的なタイポグラフィの取り入れ

明日のチャレンジも楽しみにしています！
```

## 4. トラブルシューティング

### 課題がうまく生成されない、途中でエラーになる

- インターネット接続は安定していますか？ Wi-Fiやモバイルデータ通信の状況を確認してください。
- 一度アプリやブラウザを完全に終了し、再起動してみてください。
- 課題設定の際、時間や分野などの選択肢が全て正しく選ばれているか確認してください。
- 上記を試しても解決しない場合は、コーチサポートへ連絡してください。

### デザインデータをアップロードできない

- アップロードしようとしているファイルの形式（例: JPG, PNG, GIF）や容量（ファイルサイズ）が、アプリで許可されている条件を満たしているか確認してください。
- ファイル名に日本語や特殊文字（記号など）が含まれている場合、半角英数字のみのシンプルなファイル名に変更してみてください。
- インターネット接続が安定しているか確認し、時間を置いて再度アップロードを試みてください。
- アプリやブラウザのキャッシュが影響している可能性もあるため、キャッシュクリアを試すことも有効です。（方法は各ブラウザやOSによって異なります）
